# Entscheidung zum menschlichen Einsteigertest für Zelyra 0.3.0

**Entscheidung:** Der menschliche Einsteigertest wird für 0.3.0 ausdrücklich
ausgelassen und in 0.4.0 erneut als verpflichtendes Release-Gate aufgenommen.
**Entscheidungsdatum:** 2026-10-03. **Entscheidungsträger:** Projektverantwortlicher.

Der Test wurde für 0.3.0 nicht durchgeführt. Diese Entscheidung ist kein
Testergebnis und behauptet weder eine bestandene Einsteigerstudie noch eine
unabhängige Bestätigung der Verständlichkeit. Automatisierte Onboarding- und
End-to-End-Tests bleiben davon getrennte technische Nachweise.

Für das experimentelle 0.3.0-Release wird das Restrisiko akzeptiert, dass
Installations- oder Dokumentationsschritte für neue Personen unklar sein
können. Die Veröffentlichung darf daraus keine Produktionsreife oder
Nutzerfreundlichkeit ableiten. Die bekannte Grenze bleibt in den
zweisprachigen Release-Notizen sichtbar.

## Verbindliche Wiederaufnahme in 0.4.0

Vor dem finalen 0.4.0-Release muss eine Person, die Zelyra nicht entwickelt,
die aktualisierte 0.4.0-Onboarding-Anleitung und einen veröffentlichten
0.4.0-Kandidaten auf einer sauberen Umgebung testen. Beobachtungen, benötigte
Hinweise, Blockaden und Ergebnis werden anonymisiert dokumentiert. Ein
automatisierter Test oder eine interne technische Probe ersetzt diese Abnahme
nicht. Das verbindliche Gate steht in
[`docs/release-plans/0.4.0.de.md`](../release-plans/0.4.0.de.md).
