## Observations and defects

Both reported defects are fixed in 1.0.1: Python Compose v1 is rejected before
its `ContainerConfig` crash, and Studio selects its entry point from the
existing project tree instead of the undefined `files` variable. Docker
Compose v2 or newer remains required. Ubuntu crash-report permission failures
are no longer classified as denied Docker socket access.

No further unexpected defects were found in the additional checks. The four
known observations remain bounded: deep recursion produces a controlled
diagnostic; an unbounded infinite loop is stopped externally (use
`--max-steps` for bounded execution); Decimal uses nine fractional digits and
truncates unrepresentable digits; a left-associated expression with 5,000
terms runs successfully. This Linux review is not a full Windows language
review or proof of universal error freedom.

## Reproduction

The external 80-case package was copied into a separate temporary directory;
the existing review package was not overwritten.

```bash
python3 /tmp/zelyra-101-language/pruefen.py --compiler <verified-binary> --allow-other-compiler
python3 /tmp/zelyra-101-language/wiederholen.py --compiler <verified-binary> --allow-other-compiler
python3 scripts/check_numeric_references.py --compiler <verified-binary>
python3 scripts/check_calendar_references.py --compiler <verified-binary>
```

For HTTP/SQL checks, set `ZELYRA_BIN` to the verified binary and explicitly set
`DATABASE_URL` to a dedicated test database. Run `tests/exact-numbers-e2e.py`
and `tests/temporal-sql-e2e.py` on both backends, and
`tests/temporal-api-e2e.py`. Full results include the binary hash.
