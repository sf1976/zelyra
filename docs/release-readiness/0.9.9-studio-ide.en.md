# Zelyra 0.9.9: Studio / IDE, Language Services & Font-Size Scaling

**Status:** Implemented and verified (October 13, 2026). Experimental milestone 0.9.9 (Section 4.E).
No commitment to proprietary cloud editors, external AI assistants, or telemetry.
Independent external security acceptance remains reserved for 1.0.0.

## 1. Workspace, Language Services & Compiler Integration

- **Compiler-Assisted Development Tools:**
  - Multi-file diagnostics, definition jump (`F12`), symbol reference search (`Shift+F12`), autocompletion (`Ctrl+Space`), automatic source formatting, and task execution (`⌘ Actions` / `Ctrl+Shift+P`).
  - Fast keyboard navigation and standard shortcuts (`Ctrl+S`, `Ctrl+P`, `Ctrl+F`, `Ctrl+Shift+F`, `F1` context help).
  - Project map (`project-map`) visualizing module, data, route, and logic relationships without unresolved edge guesswork.
- **Consistent Presentation & Contrasts:**
  - Full light and dark theme coverage across all Studio surfaces (editor, database workbench, project map, dialogs, statusbar).
  - Verified minimum contrast ratios (at least 4.5:1 for all text and background pairings) matching WCAG AA.
  - Accessible keyboard control (`Space`, `Enter`, `Escape`, `Tab`) and reduced motion support (`prefers-reduced-motion`).
  - State persistence: Selected appearance is persisted in `localStorage` under `zelyra-editor-theme` and restored instantly on reload without rendering flash.

## 2. Configurable Font Size & UI Scaling (User Feature Request)

- **Three-Tier Scaling:**
  - *Default (100%):* 14px CodeMirror font size, 11px tree view, 58px topbar height, 11px controls.
  - *Medium (+15% / ~1.15x):* 16px CodeMirror font size, 12px tree view, 62px topbar height, 12px controls.
  - *Large (+30% / ~1.3x):* 18px CodeMirror font size, 13.5px tree view, 66px topbar height, 13.5px controls.
- **Controls & Interaction Methods:**
  - Topbar button (`#font-size-button`, `aA` -> `aA⁺` -> `aA⁺⁺` -> `aA`) with localized accessibility labels and tooltips (`Adjust font size`).
  - Standard keyboard shortcuts:
    - `Ctrl` + `+` / `Ctrl` + `=` (Increase to Medium/Large).
    - `Ctrl` + `-` (Decrease to Medium/Default).
    - `Ctrl` + `0` (Reset to Default).
  - Command palette (`Ctrl+Shift+P`):
    - *Default font size (100%)*
    - *Medium font size (+15%)*
    - *Large font size (+30%)*
- **Persistence & Flash Prevention:**
  - Saved in `localStorage` under `zelyra-editor-font-size`.
  - Parsed in `theme.js` prior to DOM rendering (`data-font-size="medium"|"large"`), eliminating layout shifting on page load.
  - Dynamic CodeMirror reconfiguration via `editorTheme.reconfigure()` without editor reload or cursor loss.

## 3. Database Workbench, Relational CRUD Builder & Schema Edits

- **Guided Relational CRUD Resource Assistant:**
  - Visual field selection, required column markers, type annotations, and target source selection.
  - Full code and diff preview prior to explicit application (`crud-preview-grid`).
  - Concurrent modification protection (stale-file hash validation).
  - Generates readable, idiomatic Zelyra source code; manual edits are preserved and never silently overwritten.
- **Schema Column Editor:**
  - Visual table column addition and alteration (name, type, nullability/required).
  - Two-stage validation: Compiler plan and SQL impact verification prior to explicit apply.
- **Read-Only Record Browser:**
  - Secure database record preview with server-side limit (25 rows per page) and intentional selection loading.

## 4. Business Charts & Presentations in Studio

- **Business Chart Assistant:**
  - Chart creation directly from tables without requiring JavaScript library knowledge or external APIs.
  - Supports column/bar and line charts, grouping by category/text columns, aggregate functions (`count`, `sum`, `avg`, `min`, `max`), exact text filtering, and inclusive `DATE` period ranges.
  - Capped at at most 20 groups for clarity and performance.
  - Rendered as accessible SVG with synchronized data table (`<table>`) and screenreader attributes.
  - Saving and reloading verified chart configurations as reproducible project files.
- **Business Presentations & Local PDF Print Export:**
  - Slide desk assembly from saved charts, metrics, and editorial introductory text.
  - Slide layout, title, introduction, and print preview (`@media print` with clean page breaks).
  - Fully local operation without external cloud dependencies or third-party JavaScript.
