## Verification results

The full candidate CI passed on the tested commit, including workspace tests,
formatting, Clippy, generated-project Docker workflows, Studio checks, the
tenant notification workflow, invoice tutorial, fuzzing, dependency audit, and
Windows updater checks. Database compatibility passed for MariaDB 10.11, 11.4,
11.8, and 12.3, plus MySQL 8.4 runtime.

The tag workflow completed successfully. It built the Linux and Windows
x86_64 assets, verified repeated-build reproducibility, checksums, archives,
and SPDX 2.3 SBOMs, and completed its provenance/attestation jobs. I also
downloaded all four executable/archive assets and ran `sha256sum -c` against
the published sidecar files. Both SPDX documents parsed and each reported 240
packages. The published SHA-256 values are:

database container was removed afterward.

## Release boundary

These checks verify the exact 0.9.6 candidate and tag. They do not establish
independent human acceptance or production readiness. Zelyra remains
experimental; human acceptance of the exact 1.0.0 candidate is still required.
