# Zelyra 0.8.0 release verification

**Stable release:** [`v0.8.0`](https://github.com/sf1976/zelyra/releases/tag/v0.8.0),
published 2026-10-10. **Maturity:** experimental; this is not a production
approval. Independent human acceptance remains reserved for 1.0.0.

## Source and automated checks

The stable tag points to source commit
`ff862f3626e32c91027116f41182480535852029`, the merge commit for PR #38.
The complete CI workflow passed on that exact commit in
[run #38092877311](https://github.com/sf1976/zelyra/actions/runs/38092877311).
It includes the workspace tests and Clippy, MariaDB 10.11.19, 11.4.13,
11.8.9, and 12.3.3, MySQL 8.4.11, PostgreSQL 16 integration, Studio E2E
against MariaDB and PostgreSQL, dependency audit, bounded fuzzing, and Windows
and Linux checks.

The [release workflow #38092877305](https://github.com/sf1976/zelyra/actions/runs/38092877305)
passed tag validation, built both release targets reproducibly, verified the
release archives and SPDX SBOMs, generated GitHub artifact attestations, and
published the stable release. Both attestation jobs succeeded. The local GitHub
CLI lacks the attestation verification command, so a separate local signature
verification is not claimed.

## Website handbook

The German and English web handbooks and downloadable Markdown and EPUB
editions now identify 0.8.0, explain the Studio and outbox limits, and show the
0.8.0-to-1.0.0 roadmap. The live handbook pages and Markdown downloads were
fetched after the update; all 320 handbook code examples passed the website's
handbook validator.

## Scope and human acceptance

The release adds a read-only schema map and compiler-checked, explicit CRUD
source generation for the documented MariaDB and PostgreSQL Studio paths. It
also adds a bounded MariaDB transactional outbox with at-least-once delivery.
It does not claim complete PostgreSQL parity, a general queue platform, or
production approval. No human acceptance study was performed for 0.8.0; the
first independent human acceptance remains a required 1.0.0 gate.
