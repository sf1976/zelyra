# Zelyra 0.9.9 technical release rehearsal — 2026-10-12

This record describes the current technical development-branch state. It is
not a release, production approval, or human acceptance.

## Tested revision

- Branch: `release/0.9.9-pre-release`
- Commit: `1bf09ea` (`fix(runtime): avoid deprecated atomic update API`)
- Local Linux binary: `target/debug/zelyra`, SHA-256
  `89b880d753e12ac09b2fbb4dc754586d18c7a808845b991b331cb1ae00153c0d`
- Rust: `1.98.1`; Linux x86_64 with glibc 2.41

This commit fixes the Clippy error from the previous GitHub run
(`38274671930`), where `AtomicU64::fetch_update` was reported as deprecated.
Object IDs now use a checked compare-and-swap loop; exhaustion remains a
controlled runtime error.

## What remains unproven

This rehearsal does not close the open criteria in the
[0.9.9 release plan](../release-plans/0.9.9.en.md). In particular, the full
IDE/chart/presentation requirements, complete Laravel Migrator evidence,
security and privacy dispositions, upgrade/rollback coverage across the
promised platform matrix, release provenance, and all technical CI gates
remain to be closed. The bounded language corpus is Linux-specific and does
not establish general production reliability.
