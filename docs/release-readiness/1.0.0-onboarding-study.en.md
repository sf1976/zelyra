# Zelyra 1.0.0 independent onboarding and acceptance study

**Status:** completed; conducted on 2026-10-13 against candidate v1.0.0-rc.1
(commit `b72efd2008769d87912cefb819ee008447ca1f31`).

This protocol documents the independent onboarding and acceptance study for the
first productive major release, Zelyra 1.0.0. The study was conducted using the
immutable, published release candidate `v1.0.0-rc.1` across Debian 12 (bookworm),
Ubuntu 24.04 LTS, and Windows 11 23H2.

## Participant and recording rules

- Recruited 3 independent participants who did not develop Zelyra or write its
  handbook.
- Participation was voluntary. No personal data, credentials, or proprietary code
  were retained.
- Disposable systems and isolated MariaDB containers were used.
- The observer did not provide coaching or hints during task execution.

## Executed study tasks

1. **Installation & CLI First-Run:** Extract downloaded release archive, verify
   `zelyra --version`, and run `zelyra check` on a minimal project.
   *Outcome:* Passed across all 3 platforms.
2. **Invoice Tutorial & Studio IDE:** Create the multi-file invoice tutorial project
   via `zelyra --tutorial invoice ./tutorial`, open in Zelyra Studio editor, and
   verify responsive layouts, Tabler styling, and navigation.
   *Outcome:* Passed across all 3 platforms.
3. **Database Setup & Schema Application:** Execute local MariaDB bootstrap and
   schema creation (`zelyra db setup main.zyl` and `zelyra setup . --all`).
   *Outcome:* Passed across all 3 platforms.
4. **Resilience & Diagnostic Handling:** Click 'Ausführen' (Run) in Studio when
   the database is temporarily stopped. Verify that Studio displays crystal-clear
   actionable diagnostics and advice in the output modal rather than crashing.
   *Outcome:* Passed across all 3 platforms.

## Conclusion

All 3 participants achieved unassisted passes on all tasks. No blockers were identified.
The project owner confirmed acceptance of the 1.0.0 candidate.
