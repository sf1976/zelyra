# Zelyra 0.4.0 coverage-guided fuzzing record

**Date:** 2026-10-09 · **Status:** extended local evidence; not a security
review or proof of parser safety.

## Setup and commands

- `cargo-fuzz` 0.13.2, Rust nightly `1.101.0-nightly` (`a30aa9064`), and Clang
  19 on Linux x86_64.
- Build: `CC=/usr/lib/llvm-19/bin/clang cargo +nightly fuzz build`.
- After the parser fix, each target ran for 60 seconds with
  `-max_len=16384 -timeout=5`, using a temporary writable copy of its checked-in
  corpus.
- CI runs each target for 15 seconds, preserves crash artifacts, and pins the
  nightly channel to `nightly-2026-10-09`.

## Crashes found and regressions

The first lexer/parser smoke run found a panic. `cargo fuzz tmin` reduced its
input to this 9-byte case:

```text
fn e(){n*
```

The parser consumed its EOF token while reporting the missing right-hand
expression, then indexed past the token vector. It now keeps EOF available
while reporting errors and adds a sentinel EOF for callers that omit one. The
minimized input is checked in at
[`fuzz/corpus/lexer_parser/parser_missing_rhs`](../../fuzz/corpus/lexer_parser/parser_missing_rhs).

An extended lexer/parser run then found a stack overflow after 2,601,330
executions. The 2,946-byte input contains deeply nested array and index
expressions. `cargo fuzz tmin` did not produce a smaller reproducer, so the
original failing input is retained at
[`fuzz/corpus/lexer_parser/parser_recursive_stack_overflow`](../../fuzz/corpus/lexer_parser/parser_recursive_stack_overflow).
The parser now caps recursive parser nesting at 32 frames and returns a normal
parse error. Regression tests cover the retained input and deeply nested array
expressions, unary operators, blocks, types, and match patterns. All four
60-second runs completed without another crash.

## Remaining evidence

The 15-second CI job passed on the fixed commit `19e8778` as part of
[PR CI run 37971762729](https://github.com/sf1976/zelyra/actions/runs/37971762729).
The full integration job, dependency audit, four-version MariaDB matrix,
Windows updater, and Linux/Windows release artifact builds also passed. Release
publication and artifact attestations were skipped because this was a pull
request. Longer candidate-specific fuzzing and an independent security review
remain separate evidence. Retain any new crash, minimize it where possible,
and add a focused regression test before closing the gate.
