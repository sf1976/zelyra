## Acceptance boundary

Zelyra 0.9.0 is a stable release that remains experimental and is not approved
for production use. Automated CI and packaging do not replace independent
security review, production-readiness evidence, or the human onboarding and
product acceptance planned for the immutable 1.0.0 candidate.
