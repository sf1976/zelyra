# 0.9.9: Database Matrix, Transactions, and Relational CRUD

Date: 2026-10-13. Unpublished development package. [Deutsch](0.9.9-relational-crud-matrix.de.md)

This package closes technical release gate **Section 4.A** (Database Matrix,
Transactions, and Relational CRUD) for Zelyra 0.9.9. It validates exact database
engine versions across MariaDB 11.4.13, MySQL 8.4.11, and PostgreSQL 16.15 using
isolated disposable containers on ephemeral ports with zero impact on production
services. In addition to real foreign keys, migration preflights, and restrictive
deletion, write lock wait boundaries (`innodb_lock_wait_timeout`) were hardened
and verified on MySQL.

## Technical Details

1. **MySQL Lock Wait Hardening:** In `database/src/lib.rs`, `mysql_timeout_statement`
   and `mysql_session_timeout_statement` configure `innodb_lock_wait_timeout = lock_wait_seconds`
   in addition to `max_execution_time`. This bounds row locks and DML statements to the
   allocated query budget rather than MySQL's default 50s stall.
2. **Preflight Check `E-DB-005`:** Detects foreign key constraint violations in existing
   table data before applying DDL migrations, reports offending keys and tables, and halts
   safely without altering existing records.
3. **Restrictive Foreign Keys:** Relational schema enforces RESTRICT by default; parent
   records cannot be deleted while referenced by children.
4. **Relational Option Loading:** `load_relation_options` enforces tenant scoping at
   the query level based on the caller's active tenant ID.

## Limits and Open Gates

Gate 4.A demonstrates relational CRUD and transaction cycles on MariaDB, MySQL, and
PostgreSQL. It does not establish full PostgreSQL auth/MFA parity or universal dialect
portability. Chained audit remains exclusive to MariaDB/MySQL.
