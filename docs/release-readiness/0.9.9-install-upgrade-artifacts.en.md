# Zelyra 0.9.9: Installation, Upgrade, Rollback & Release Artifacts

**Status:** Implemented and verified (2026-10-13). Experimental 0.9.9 milestone (Section 4.D).
No commitment to automated zero-downtime cluster migrations or proprietary backup engines.
Independent security and human product sign-off remain reserved for 1.0.0.

## 1. Clean End-User Installation & Onboarding

- **Prefix Installation without Toolchain Dependencies:**
  - `install.sh --no-rustup` installs precompiled release binaries to `$PREFIX/bin/zelyra`.
  - Zero dependency on Rustup, Cargo, or C build tools on target environments.
  - Rejection of malformed or incomplete release tags.
- **Verification & Lifecycle:**
  - `install.sh --check` validates executable permissions and version output (`0.9.9`).
  - Idempotent reinstallation safely replaces verified binaries.
  - Clean uninstallation via `install.sh --uninstall` leaves zero residual files.
- **MariaDB Project Onboarding:**
  - Project initialization produces clean project structures including Docker Compose and `.env`.
  - `zelyra doctor` validates dependencies; schema bootstrap completes without error.

## 2. Guided Invoice Tutorial & Business Calculations

- **Modular Project Structure:**
  - CLI generation via `zelyra --tutorial invoice [dir] --no-start`.
  - Structured modules across `src/database.zyl`, `src/shell.zyl`, `src/customers.zyl`, `src/items.zyl`, `src/invoices.zyl`, and `src/dashboard.zyl`.
  - Idempotent schema migrations on MariaDB without destructive DDL changes.
- **Calculations & Print Layout:**
  - Accurate commercial net, 19% VAT, and gross calculations.
  - Tabler Core 1.6.1 is served locally without external CDN calls.
  - Print layout automatically suppresses navigation and interactive elements via `@media print`.
- **Resolution of Left-Edge Column Collapse (258px Narrow-Column Layout Bug):**
  - *Root Cause:* Having `class="zelyra-app"` on the `<html>` root element interacted with the default Studio sidebar grid `.zelyra-app { display: grid; grid-template-columns: 258px minmax(0, 1fr); }`, constraining the `<body>` element (the first child) to a fixed 258px column on the left edge. When `zelyra.theme.css` was missing, this bug appeared without mitigation.
  - *Fix in `web/assets/zelyra.css`:*
    - Added `html.zelyra-app, body.zelyra-app { display: block; width: 100%; min-height: 100vh; }` ensuring root and body elements are never treated as grid columns.
    - Added `main:not(.zelyra-learning-panel):not(.page-body)` preventing default card borders and margins from constraining the Tabler page body.
  - *Fix in Theme (`examples/invoice_tutorial.theme.css` & `examples/invoice_tutorial/zelyra.theme.css`):*
    - Explicit reset of `html.zelyra-app, body.zelyra-app, .zelyra-app` to `display: block !important; width: 100% !important;`.
    - Included `zelyra.theme.css` directly within `examples/invoice_tutorial/` so running `zelyra serve` directly immediately loads the local theme.

## 3. Backup, Restore, and Server Crash Recovery

- **Scoped Backup:**
  - `mariadb-dump` executed with strictly bounded privileges (read-only table access).
  - Atomic handling: Backups stream to temporary `.partial` files. On interruption or failure, temporary files are removed; partial dumps never masquerade as valid backups.
- **Target-Isolated Restore:**
  - Restores target dedicated database instances with isolated user privileges.
- **Crash Recovery at DDL/Journal Boundaries:**
  - Interruptions at the DDL/journal boundary leave the database in an inspectable, safe state.
  - Fresh migration plans accurately detect actual table states and resume cleanly without data loss.

## 4. Reproducible Release Artifacts, Checksums, and Provenance

- **Metadata and Version Consistency:**
  - Strict parity verified across `Cargo.toml`, scripts, and binary output (`zelyra --version -> 0.9.9`).
- **Deterministic Packaging:**
  - Built with `SOURCE_DATE_EPOCH` to guarantee reproducible tarball hashes.
  - SHA-256 sidecars (`.sha256`) validated for all release archives.
- **Archive Path Safety:**
  - Enforced absence of leading slashes (`/`) and directory traversal sequences (`..`).
- **Release Artifact Smoke Testing:**
  - Release archives extracted, binary executed, and system checks verified via `tests/release-artifact-smoke.sh`.
