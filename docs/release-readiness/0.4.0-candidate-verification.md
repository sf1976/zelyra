## Verification evidence

- Candidate release: <https://github.com/sf1976/zelyra/releases/tag/v0.4.0-rc.1>
- Tag source: `git rev-parse 'v0.4.0-rc.1^{commit}'` returned
  `97027dea40835781f599b570a97df5b0426bf424`.
- [Release workflow run #170](https://github.com/sf1976/zelyra/actions/runs/38005938599)
  passed Linux and Windows archive/SBOM generation and verification, and both
  attestation jobs, before publishing the prerelease.
- Downloaded Linux and Windows archives and SPDX JSON files. Their SHA-256
  values above matched both the release API asset digests and the published
  `.sha256` sidecars. `scripts/verify_release_artifacts.py` verified archive
  contents, paths, file types, sidecars, and the Linux binary. The Windows
  workflow ran its packaged binary on the Windows runner. `scripts/verify_sbom.py`
  verified both SPDX 2.3 files against their corresponding release binaries
  (175 packages each).
- Fetched the GitHub attestation bundles for the Linux `.tar.gz` and Windows
  `.zip` archive digests. `cosign verify-blob-attestation --new-bundle-format`
  returned `Verified OK` for both, with issuer
  `https://token.actions.githubusercontent.com` and certificate identity
  `https://github.com/sf1976/zelyra/.github/workflows/release.yml@refs/tags/v0.4.0-rc.1`.
  The workflow supplied the matching per-platform SPDX file as the attestation
  SBOM input; the SBOMs were independently checked and hashed above.
- `tests/published-release-smoke.sh v0.4.0-rc.1 v0.3.0` passed on Linux
  x86_64: it installed and reinstalled the published candidate, verified the
  installed version, confirmed the updater identified the candidate as newer
  than stable `v0.3.0`, then restored and verified the published `v0.3.0`
  binary in the same isolated install root.
- The exact candidate source commit also passed [main CI run #447](https://github.com/sf1976/zelyra/actions/runs/38005200433)
  and the later tag CI is tracked in [run #448](https://github.com/sf1976/zelyra/actions/runs/38005938608).

This record verifies the published candidate. It does not claim an external
security audit, production suitability, Windows installation on a physical
