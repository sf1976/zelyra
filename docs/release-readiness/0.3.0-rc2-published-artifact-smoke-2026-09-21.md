# Zelyra 0.3.0-rc.2 published artifact evidence

**Date:** 2026-09-21  
**Candidate:** `v0.3.0-rc.2`  
**Tagged commit:** `9aa04664da53e8b2aef2ad99f075c2774b7543fb`

## Native candidate artifacts

The [tagged release workflow](https://github.com/sf1976/zelyra/actions/runs/35591071729)
completed successfully. It built and verified Linux x86_64 and Windows x86_64
archives and standalone binaries, including SHA-256 sidecars, archive safety,
stable CLI version output (`zelyra 0.3.0`), and repeated-build equality.

## Published Linux smoke test

On the Linux x86_64 workspace host, the following command completed successfully:

```text
./tests/published-release-smoke.sh v0.3.0-rc.2
```

It downloaded the published archive through `install.sh`, verified its SHA-256
checksum, installed `zelyra 0.3.0`, repeated the installation, and ran
`zelyra update --check`. The update check correctly reported that the candidate
is newer than the latest stable `0.2.0` and made no changes.

This evidence closes the candidate-artifact, published-install/update-smoke,
and artifact/update-verification gates. It does not close the human onboarding
study, and it is not approval to publish final `v0.3.0`.
