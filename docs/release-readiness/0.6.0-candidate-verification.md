## Scope limits

The route command inventories recognized routes and rejects overlapping routes
with the same HTTP method using `E-ROUTE-001`. `zelyra db map` is read-only;
module ownership is advisory. PostgreSQL support in this release is a bounded,
experimental direct-SQL and transaction slice tested against PostgreSQL 16. It
does not establish generated web/CRUD support or full PostgreSQL parity. MySQL
Server support is not claimed. This release is not production-approved and does
not include human acceptance evidence.
