# Zelyra 0.3.0 final release verification

Release date: 2026-10-03  
Tag: [`v0.3.0`](https://github.com/sf1976/zelyra/releases/tag/v0.3.0)  
Source commit: [`cd0600a73c22ed84f40aef870c8128ce2cb45be0`](https://github.com/sf1976/zelyra/commit/cd0600a73c22ed84f40aef870c8128ce2cb45be0)  
Release workflow: [run 37104281398](https://github.com/sf1976/zelyra/actions/runs/37104281398)

## English

The final tag-validation, Linux x86_64 build, Windows x86_64 build, package
verification, and GitHub publication jobs all completed successfully.
Published assets:

- Linux: `zelyra-v0.3.0-x86_64-unknown-linux-gnu.bin` and `.tar.gz`, each with
  a SHA-256 sidecar.
- Windows: `zelyra-v0.3.0-x86_64-pc-windows-msvc.exe` and `.zip`, each with a
  SHA-256 sidecar.

`tests/published-release-smoke.sh v0.3.0` passed on Linux x86_64. It downloaded
the published archive, verified its checksum, installed the compiler, repeated
the installation, and confirmed `zelyra update --check` reports the installed
release as current. Windows packages were built and validated by CI; this
record does not claim a native Windows interactive-install smoke test.

The 0.3.0 human onboarding study was not conducted. Its deferral is the explicit
project-owner risk decision in the [bilingual decision record](0.3.0-human-gate-decision.en.md),
not usability evidence. An independent human acceptance remains mandatory
before the final 0.4.0 release.

## Deutsch

Die Jobs für Tag-Validierung, Linux-x86_64-Build, Windows-x86_64-Build,
Paketprüfung und GitHub-Veröffentlichung waren erfolgreich.
Veröffentlichte Artefakte:

- Linux: `zelyra-v0.3.0-x86_64-unknown-linux-gnu.bin` und `.tar.gz`, jeweils
  mit SHA-256-Prüfdatei.
- Windows: `zelyra-v0.3.0-x86_64-pc-windows-msvc.exe` und `.zip`, jeweils mit
  SHA-256-Prüfdatei.

`tests/published-release-smoke.sh v0.3.0` war unter Linux x86_64 erfolgreich.
Das Skript lud das veröffentlichte Archiv, prüfte die Prüfsumme, installierte
den Compiler, wiederholte die Installation und bestätigte, dass
`zelyra update --check` die installierte Version als aktuell erkennt. Die
Windows-Pakete wurden durch CI gebaut und geprüft; ein interaktiver nativer
Windows-Installations-Smoke-Test wird hier nicht behauptet.

Die menschliche Einsteigerstudie für 0.3.0 wurde nicht durchgeführt. Ihre
Verschiebung ist die ausdrückliche Risikoentscheidung des
Projektverantwortlichen im [zweisprachigen Entscheidungsprotokoll](0.3.0-human-gate-decision.de.md),
kein Nachweis der Nutzerfreundlichkeit. Vor dem finalen 0.4.0-Release bleibt
eine unabhängige menschliche Abnahme verpflichtend.
