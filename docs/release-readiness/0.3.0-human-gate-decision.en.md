# Zelyra 0.3.0 human onboarding gate decision

**Decision:** Explicitly defer the human onboarding test from 0.3.0 and restore
it as a mandatory release gate for 0.4.0. **Decision date:** 2026-10-03.
**Decision authority:** project owner.

The test was not conducted for 0.3.0. This decision is not a test result and
does not claim a successful novice study or independent confirmation that the
instructions are understandable. Automated onboarding and end-to-end tests
remain separate technical evidence.

For the experimental 0.3.0 release, the residual risk that installation or
documentation steps may be unclear to a new user is accepted. Publication must
not imply production readiness or proven usability. The limitation remains
visible in the bilingual release notes.

## Mandatory follow-up in 0.4.0

Before the final 0.4.0 release, a person who does not develop Zelyra must test
the updated 0.4.0 onboarding guide and a published 0.4.0 candidate in a clean
environment. Redacted observations, required hints, blockers, and the result
must be recorded. An automated test or internal technical rehearsal cannot
replace this acceptance. The mandatory gate is in
[`docs/release-plans/0.4.0.en.md`](../release-plans/0.4.0.en.md).
