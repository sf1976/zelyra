Required for the stable 1.0.0 release. Complete only after technical release
gates pass for an immutable, published candidate. An incomplete branch build
does not qualify. If a blocker is found, publish a corrected candidate and
repeat the study against its exact assets.

- Candidate commit: PENDING (full 40-character SHA)
- Candidate assets and checksums: PENDING
- Platform and clean-machine details: PENDING
- Completed on: PENDING
- Participant: independent non-developer; identity omitted
- Tasks (mark PASS, FAIL, or N/A with a reason):
  - Verify the downloaded archive and run `zelyra --version`.
  - Install on a clean supported machine without a Rust toolchain.
  - Initialize a project from the documented starter and run its first page.
  - Follow the documented MariaDB setup and run a database-backed starter.
  - Stop and restart the application and database, then repeat the documented
    health and application checks.

    flow, including one recovery code when MFA is enabled in the candidate.
  - Build a small edit, run the documented checker, and explain any diagnostic
    using the handbook.

    needed and which documentation resolved the issue.

unreleased until this decision is explicitly PASS. A failed or inconclusive
study is not acceptance evidence.
