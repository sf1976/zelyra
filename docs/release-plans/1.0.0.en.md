# Zelyra 1.0.0 major release plan

**Status:** planned; not a stable release promise. `v1.0.0` is the first major
publication and the mandatory target for all deferred independent human tests.

## Release gates

- [ ] Freeze the 1.0.0 product scope, support matrix, compatibility promises,
  and documentation before preparing the final candidate.
- [ ] Pass technical, security, dependency, artifact, checksum, SBOM, and
  provenance checks on the exact candidate revision.
- [ ] Publish an immutable 1.0.0 release candidate and conduct the independent
  human study using its exact assets and shipped documentation.
- [ ] Fix every human-study blocker, verify a corrected immutable candidate,
  and repeat the affected study tasks.
- [ ] Complete the bilingual human acceptance record with the exact candidate
  tag and commit, participant/task evidence, redacted observations, blockers,
  and the project owner's explicit decision.
- [ ] Publish stable `v1.0.0` only after every technical gate and the human
  acceptance decision pass.

Human acceptance is specific to the recorded tasks and participants. It does
not establish general usability, production readiness, security certification,
or correctness for arbitrary programs.
