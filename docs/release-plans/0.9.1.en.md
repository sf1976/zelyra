# Zelyra 0.9.1 release plan: IDE foundation

**Status:** release candidate under review; experimental and not approved for
production. Independent human product acceptance remains reserved for 1.0.0.

## Scope

- Local Studio opens and edits project files, visibly tracks unsaved changes,
  saves with `Ctrl+S`, and shows compiler diagnostics in the Problems panel.
- Reloading the Studio tab resumes its local session without leaving the session
  token in the address bar.
- Paths remain inside the project. Stale file hashes, path traversal, secret
  files, protected project files, and overwriting existing destinations are
  rejected.
- The invoice tutorial calculates net, 19% VAT, and gross from stored line
  items. The print view can be saved as PDF with the browser; the tax rate is a
  learning assumption, not a legal or accounting claim.
- Language line 0.1 uses `#` for line comments and standalone `##` lines as
  non-nesting block-comment delimiters. Existing `//` comments remain readable.

## Exit criteria

- [ ] Browser flow covers session start, unsaved edits, reload warning, keyboard
  save, visible compiler diagnostics, and clean restart.
- [ ] MariaDB and PostgreSQL Studio flows pass for schema overview, compiler
  preview, stale-hash conflict, and explicit apply.
- [ ] Security checks cover missing tokens, wrong origin, path traversal, secret
  files, stale content, and protected project files.
- [ ] Workspace, editor bundle, Windows/Linux packages, MariaDB matrix, MySQL
  and PostgreSQL workflows, fuzzing, dependency review, and handbook snippets
  pass for the candidate.
- [ ] Version metadata, bilingual release notes, support boundaries, and the
  website handbook match published `v0.9.1`.

This release is not human acceptance evidence or production approval. Studio
receives compiler-backed language services in 0.9.2; broader capabilities stay
in their respective roadmap milestones.
