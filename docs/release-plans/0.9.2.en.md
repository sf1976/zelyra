# Zelyra 0.9.2 Release Plan: IDE Language Services

**Status:** in progress · experimental · no production approval. Independent human
product acceptance remains reserved for 1.0.0.

## Implemented and locally checked

- [x] F1 and the help control open bilingual help for core language terms at the
  cursor. File properties show path, type, save state, and format/check actions.
- [x] The action finder is available from the toolbar and Ctrl+Shift+P, filters
  available tasks, and supports keyboard navigation.
- [x] `zelyra --help` ends with German and English getting-started paths for
  both the invoice tutorial and a minimal project; key commands explain their
  purpose and database requirements.
- [x] Completion adds declarations from the linked project model to language
  keywords; Ctrl+Space opens the suggestion list.
- [x] Zelyra files receive compiler diagnostics for the current, possibly
  unsaved source after a short pause. Checking uses a private temporary project
  copy, leaves project files untouched, and converts source positions for the
  browser editor.
- [x] Rust verification of unsaved-source checking and a Chromium browser flow
  for F1, file properties, diagnostics before saving, and subsequent save.

Extending the action finder to all project tasks, local-variable and
context-type completion, symbol/route properties,
project-wide search, and integrated development tasks remain open.

## Goal

Studio should make as many everyday language and web-framework tasks as
possible understandable and directly operable. Properties panels, task selection,
and guided flows should reduce manual detail work and command memorization. The
compiler remains the source of truth for syntax, symbols, diagnostics, and project
relationships; every generated change remains ordinary, reviewable Zelyra source.

## Scope

- A context-sensitive help and properties sidebar shows file information and
  supported language terms in clear language. F1 and the help control open it;
  file properties provide direct format and check actions. Expanding this to
  symbols, routes, views, forms, and resources remains in scope. Supported edits
  can be checked in a source preview and explicitly applied.
- A task/command finder makes supported language and framework actions easy to
  discover. Help for the command at the cursor can be requested with F1 or a
  visible help control and shows its description, options, examples, and known
  limitations.
- Where the project model and compiler allow fast results, Studio updates
  hints while typing. Full compiler diagnostics can be requested without leaving
  the IDE for a shell. Diagnostics have correct file and source locations.
  Incomplete or unchecked states are visible; compiler errors are not hidden as
  warnings.
- Compiler-backed completion, symbol navigation, and find/references cover the
  documented language compatibility line 0.1.
- Format, check, run, and supported verification tasks can start in Studio.
  Progress, completion, output, and failures are visible; secrets are redacted.
- Project, module, import, route, and resource relationship diagrams are
  deterministic views of the compiler project model. Selection navigates to
  source, object, and diagnostics. Unresolved edges are marked unknown.

## Exit criteria

- [ ] Browser E2E covers property selection, requestable command help, live
  diagnostics, navigation targets, keyboard access, and resizing.
- [ ] Positive and negative multi-file projects cover completion, navigation,
  symbols, file switching, and diagnostic ranges.
- [ ] Formatting is repeatable and writes only after an explicit action.
  Compiler tasks show status and redacted output.
- [ ] Diagram data is deterministic across runs and includes source locations;
  unknown or dynamic relationships are not guessed.
- [ ] Keyboard operation, focus, screen-reader labels, and contrast are verified
  for new Studio controls.
- [ ] Workspace, editor bundle, installers, full E2E suite, MariaDB matrix,
  MySQL/PostgreSQL subsets, fuzzing, dependency audit, and Linux/Windows
  artifacts pass on the exact candidate.
- [ ] German and English references, roadmap, release notes, and handbook match
  shipped behavior and database limits.

## Boundaries

The graphical schema designer for adding/changing table fields and creating the
selected database from Studio are planned for 0.9.3. The 0.9.2 properties
sidebar and guided IDE workflows do not manage database schemas. Full
MySQL/PostgreSQL parity, arbitrary shell execution, cloud dependencies, and
external AI services are out of scope.

This release does not replace independent human product acceptance and is not
production approval.
