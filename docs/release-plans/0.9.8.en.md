# Zelyra 0.9.8 release plan: production-readiness rehearsal

**Status:** planned. This is the stabilization rehearsal before the 0.9.9
feature freeze. It is not human acceptance or production approval.

## Goals

- Exercise clean installation, upgrade, rollback, migration, backup, and restore
  on the supported operating systems and the exact promised MariaDB, MySQL,
  and PostgreSQL server matrix.
- Close documentation, dependency/license review, security finding, resource
  bound, secret-redaction, and release artifact gaps. Every remaining finding
  must have an owner and a documented disposition; release blockers stay open.
- Validate the complete 1.0 workflow: create a project, edit it in Studio,
  inspect the database, build relational CRUD, send test mail through a local
  SMTP sink, and use the notification center.
- Measure startup, common CRUD paths, and bounded resource use on reproducible
  fixtures. Publish methods and results without unsupported performance claims.
- Validate bilingual handbook examples, offline documentation, SBOMs,
  attestations, checksums, and the immutable candidate publication process.
- Complete the staged Laravel Migrator scope from 0.9.3–0.9.7. Validate its
  supported Laravel/package matrix, static source evidence and locations,
  route-to-data graph, business/security uncertainty reporting, and separate
  compiler-valid scaffold output. Confirm source files and databases remain
  untouched, reports and output paths cannot overlap the input, and secrets,
  personal records, and production data never appear in artifacts.

## Exit criteria

- [ ] All rehearsals pass from clean environments with reproducible evidence.
- [ ] Every database workflow promised for 1.0 has an exact server-version
  result and a documented limitation list.
- [ ] Security, dependency, privacy, migration, recovery, and authorization
  findings have verified dispositions; no release blocker remains.
- [ ] The Studio, invoice tutorial, SMTP mail, and notification-center workflows
  work together without mandatory cloud services, external AI, or telemetry.
- [ ] Laravel analysis fixtures cover tenant boundaries, foreign-key relations,
  transactions, decimal money, authorization, files, jobs, and integrations.
  Unsupported and ambiguous behavior is reported for manual work; generated
  scaffolding is clearly separated from verified behavior transfer.
- [ ] All bilingual documentation and generated handbook exports match shipped
  behavior and their examples pass validation.
- [ ] The 0.9.9 feature freeze scope and evidence checklist are reviewed and
  ready. Independent human acceptance remains reserved for the exact 1.0.0
  candidate.
