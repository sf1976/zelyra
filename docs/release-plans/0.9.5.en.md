# Zelyra 0.9.5 release plan: first-party mail and SMTP

**Status:** planned; experimental until all gates pass. This milestone adds
complete, local-first application mail delivery without requiring a cloud mail
provider.

## Scope

- Provide an explicit Zelyra mail API for text and HTML messages, named
  templates, safely encoded headers, attachments within documented size limits,
  and compiler-checked capabilities.
- Support SMTP authentication, implicit TLS, and STARTTLS with certificate
  verification. Never downgrade or send credentials over a plaintext connection.
- Bound connection, read, and write timeouts. Integrate retryable delivery with
  the transactional outbox while documenting at-least-once delivery and the
  duplicate window.
- Include local configuration guidance and a local SMTP sink for development
  and automated tests. Do not require an external account or service.

## Exit criteria

- [ ] Positive and negative integration tests cover SMTP success, authentication,
  certificate rejection, TLS negotiation, timeout, restart, retry, and failure
  recovery using a local sink.
- [ ] Tests cover MIME encoding, template escaping, attachment limits, secret
  redaction, capability checks, and the delivery duplicate window.
- [ ] Configuration, environment variables, security classification, defaults,
  and command effects are documented in English and German.
- [ ] Generated projects explain how to develop and test mail offline without
  publishing credentials or sending messages to real recipients.
- [ ] Release CI, dependency review, release artifacts, checksums, SBOMs, and
  handbook validation pass for the exact candidate.

No release claim may imply exactly-once delivery, universal SMTP relay
compatibility, or production approval. Security review and the 1.0.0 human
acceptance gate remain required.
