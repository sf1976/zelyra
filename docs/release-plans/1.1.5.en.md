# Zelyra 1.1.5 release plan

Scope: the reusable local package and module workflow. No Laravel importer,
remote registry, publisher signature system, or unverified data connector is
part of this release. The AST interpreter remains the default backend.

## Release gates

- [x] Package compatibility, lock integrity, path confinement, effects, module
  settings, and generated package scaffolding have positive and negative tests.
- [x] The business-module examples lock, check, and run; CSV import/export
  validation is covered across the supported execution backends.
- [x] Package guides, release notes, changelog, command help, and both roadmaps
  match the implemented behavior and state its limits.
- [x] `cargo fmt`, locked workspace check and tests, Clippy, handbook checks,
  release metadata validation, and artifact smoke tests pass.
- [x] Linux and Windows release builds complete in CI; archives, checksums, CLI
  startup, embedded Studio assets, and installation metadata are checked.
- [x] The release candidate is based on v1.1.2, contains reviewed release work,
  and has matching workspace version, lockfile, and release metadata. The
  public tag is created only after all gates pass.

## Known limits

Package checksums do not establish publisher identity. There is no registry or
remote package download. CSV import is bounded to 16 MiB and stays in memory.
ODBC, Excel export, graphical PDF generation, ordinary application-page module
settings, and complete AST/MIR/Bytecode parity are not claimed by this release.
