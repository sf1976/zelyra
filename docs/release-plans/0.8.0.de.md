# Zelyra 0.8.0: visuelle Datenbankkarte und geführtes CRUD

**Status:** geplant. Dieses Release ergänzt das lokale Studio um sichere,
compilergeprüfte Datenbank- und Quelltextabläufe. Es ist kein Produktivrelease.

## Ergebnis für Entwickler

Entwickler können eine konfigurierte Projektdatenbank öffnen, Tabellen und
Beziehungen überblicken, eine Tabelle auswählen, ein erzeugtes CRUD-Modul
prüfen und die Quelltextänderung nach erfolgreicher Compilerprüfung anwenden.
Datenbankinhalte bleiben in diesem Release schreibgeschützt.

## Umfang

- Eine schreibgeschützte Datenbankkarte zeigt Tabellen, Spalten, Schlüssel,
  Beziehungen und Abweichungen zwischen deklariertem und live vorhandenem
  Schema. Bekannte Quellmodule werden den Deklarationen zugeordnet.
- Entwickler wählen Tabelle und Felder aus, sehen den erzeugten Zelyra-Quelltext,
  lassen ihn vom Compiler prüfen, kontrollieren den Diff und übernehmen die
  Änderung ausdrücklich.
- Der visuelle Ablauf verändert weder Datenbankschema noch Datensätze. Er
  erzeugt keine stillen Änderungen und überschreibt keine seit der Vorschau
  geänderte Datei.
- Das Korpus für Linie 0.1 wird für Lexer, Parser, Typprüfung und Formatter
  erweitert. Jede Grammatikfamilie erhält gültige und ungültige Fixtures;
  Formatter-Idempotenz wird geprüft.
- Der Ablauf bleibt lokal und überträgt keinen Quelltext an externe Dienste.
  Datenbank-Introspektion wird je Backend getrennt dokumentiert.

## Release-Gates

- Schemas mit fehlenden, zusätzlichen, umbenannten, nullable und verknüpften
  Spalten sowie unbekannten Merkmalen prüfen; Unsicherheit muss sichtbar bleiben.
- Belegen, dass erzeugter Quelltext dieselben Compilerprüfungen wie manuell
  geschriebener Code besteht.
- Veraltete Vorschau, Abbruch, fehlerhafte Metadaten und Schreibschutz für jedes
  unterstützte Introspektions-Backend testen.
- Das vollständige Sprachkorpus auf dem exakten Release-Kandidaten ausführen.
- Zweisprachiges Editorhandbuch, Datenbankmatrix und Beispiele aktualisieren.

Das Release verspricht weder eine vollständige IDE noch einen uneingeschränkten
Datenbankdesigner oder Parität außerhalb der geprüften Matrix.
