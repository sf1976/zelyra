# Zelyra 0.95.0 release plan: production readiness rehearsal

**Status:** stabilization work is in progress. The first corpus audit adds
nested-record, array, typed-map, deterministic-output, and denied-capability
fixtures. The wider rehearsal and review gates remain open. This is not human
acceptance and is not approved for production.

## Goals

- Complete and review the production scope, language reference, support
  matrices, installation, upgrade, backup, recovery, and security guidance.
- Close known migration, rollback, authorization, dependency, and release
  artifact review gaps or record a specific blocker that prevents 0.99.
- Run clean-machine and clean-database rehearsals for the supported install and
  upgrade paths on the supported operating systems.
- Audit the 0.1 language corpus against the documented grammar and semantics;
  resolve gaps or mark unsupported behavior explicitly.
- Rehearse the 0.99 technical gates, checksums, SBOM/provenance, and immutable
  candidate workflow using a disposable candidate.
- Collect internal technical feedback only. Independent human acceptance
  remains reserved for the exact 1.0.0 candidate.

## Exit criteria

- [ ] Every supported database workflow maps to a reproducible version-matrix
  result and an explicit limitation list.
- [ ] Backup/restore and upgrade/rollback instructions are exercised, not merely
  documented.
- [ ] Security findings have owners and verified dispositions; unresolved blockers
  prevent advancing to 0.99.
- [ ] Bilingual docs match shipped behavior and all examples pass the handbook
  validator.
- [ ] No new large subsystem is admitted during stabilization. Feature freeze is
  formally recorded for 0.99.0.
