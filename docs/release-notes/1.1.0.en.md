# Zelyra 1.1.0

**Release:** `v1.1.0` · **Language compatibility:** `0.1`

Zelyra 1.1.0 focuses on Studio and language-specific development tools. The
released application embeds the editor and its assets in the Zelyra CLI and
works offline without Node.js, npm, a CDN, or a separate web server.

## Studio and language tools

- CodeMirror 6 with Zelyra syntax highlighting, completion, hover,
  diagnostics, definition, references, and rename.
- Compiler-backed project analysis with unsaved documents, versioned
  diagnostics, and an authenticated, bounded SSE channel.
- Typed-hole suggestions for visible bindings, checked by the compiler.
- A verification view that distinguishes proven, runtime-checked, failed,
  and unknown results.
- A project data map for declared tables, SQL, records, and UI stages, with
  static nullability notices.
- Static page/view preview with explicit sample data, an isolated browser
  context, and source links. Opening a file does not execute project code.
- Theme color edits written as reviewable changes to `zelyra.theme.css`.
- Capability review with explicit grant changes, plus step-budget execution
  and a recursion overview.
- Real PDF bytes in the preview and MariaDB outbox status; requeue uses the
  existing domain operation and does not send immediately.
- Semantic rename for supported resolved symbol kinds, and file rename with
  an import plan, compiler validation, and recovery journal.
- Standalone `zelyra lsp` JSON-RPC language server over stdio.

## Language and runtime

1.1.0 also includes type-checked string interpolation and opt-in mutable local
arrays with in-place index updates, `push_mut`, and `pop_mut`. It retains the
language features from the previous 1.0.7 baseline.

## Verification and limits

- The embedded JavaScript bundle measures 560,316 bytes (547.2 KiB), below
  the 600 KiB hard limit. 400 KiB remains an optimization goal.
- Compiler jobs are bounded and versioned, but running compiler analysis is
  not cooperatively preemptible.
- Rename runs only for semantically resolved, supported symbol kinds.
  Ambiguous or unresolved references cause the edit plan to be rejected.
- PDF generation renders text and page breaks. It does not visually reproduce
  CSS, images, or charts.
- Bytecode/AOT and the AST-interpreter redesign are outside 1.1.0 and remain
  planned for 1.3.0.

The complete artifacts and checksums, verified through the release gates, are
listed on the [GitHub release page](https://github.com/sf1976/zelyra/releases/tag/v1.1.0).
