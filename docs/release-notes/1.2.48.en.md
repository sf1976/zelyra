# Zelyra 1.2.48

## Fused mutable array index increments in Bytecode

For `mutable_array[index] += <Int literal>`, the Bytecode compiler can emit a
single verifier-checked operation that validates the index and updates the
array. It charges the source step only after the bounds check, preserving the
error order shared with AST and MIR. Other right-hand expressions continue to
use the general checked path.

The versioned Bytecode artifact format advances to v30. This format is
experimental and incompatible with earlier Bytecode artifacts; AST remains the
reference backend and default.

A pinned, same-host benchmark with 20,000 integers and 100,000 indexed updates
measured the Bytecode median at 33.77 ms before and 29.45 ms after the change
(12.8% lower). This is one workload-specific result, not a general performance
claim.
