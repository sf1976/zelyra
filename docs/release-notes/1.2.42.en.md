# Zelyra 1.2.42

This release improves the Laravel website importer's view analysis. It resolves
literal Blade `@extends`, `@include`, `@includeIf`, `@includeWhen`, `@each`, and
local anonymous `@component` references against the scanned
`resources/views` inventory. The report records deterministic dependency edges
with source locations, unresolved references, and composition cycles in
`VIEW_LINKS.json` and `VIEW_LAYOUTS.md`.

This is a source-analysis feature, not Blade translation. It does not generate
page routes, translate layouts or fragment behavior, execute PHP, read Laravel
`.env` files, or claim complete website migration. The project check against
`/opt/siedelmann-laravel/app` inventoried 576 PHP files and found 2,274
importer findings; 1,393 remain unresolved or require manual work. It resolved
231 view-composition edges with no unresolved literal references or cycles.

## Verification

- Full GitHub PR CI passed on the merged implementation, including workspace

  and browser integration suite, coverage-guided fuzzing, Windows updater

- The read-only acceptance-project check passed. It generated a temporary
  scaffold, compiler-checked it, and removed the generated files afterward.
- `VIEW_LINKS.json`/`VIEW_LAYOUTS.md` report 231 resolved composition edges,
  zero unresolved literal references, and zero detected cycles for the
  inventoried project views. These counts describe the scanned Blade view
  graph, not translated application behavior.
