# Zelyra 1.2.54

## Import guidance in Zelyra Studio

After typing `import "`, Studio suggests matching `.zyl` source files from the
current project. It filters out the active file, duplicate imports, other file
types, and comment text. Once an alias is assigned, existing compiler-aware
completion continues with that module’s public declarations, making the import
flow easier to discover without weakening compiler checks.

This release also updates the transitive `ctutils` dependency to 0.4.5 in
response to [RUSTSEC-2026-0385](https://rustsec.org/advisories/RUSTSEC-2026-0385.html).
