# Zelyra 1.2.46

## Consistent collection index behavior

Array and tuple index errors now use shared runtime semantics across AST, MIR,
and verified Bytecode, including encoded and decoded Bytecode artifacts.
Out-of-range mutable array updates report the same diagnostic and source span.
For indexed compound assignment, Bytecode checks the existing target before
evaluating the right-hand side, matching AST and MIR when that expression has
side effects.

The verifier-checked `ArrayIndexCheck` instruction advances the Bytecode
artifact format to v29. Bytecode remains an experimental, opt-in backend; this
release does not claim general backend parity or change the default backend.
