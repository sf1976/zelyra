# Zelyra 1.2.51

## Zelyra Studio liest das Projekt mit dem Compiler

Die Studio-Startseite liest die lokale Compiler-Projektkarte und fasst
erkannte Module, Datenmodelle, Webflächen und SQL-Abfragen zusammen. Aus dem
Projektkontext empfiehlt sie einen passenden nächsten Schritt und kennzeichnet
eine unvollständige Analyse sichtbar. Die Übersicht ändert keine Quelldateien
und benötigt keinen KI- oder Cloud-Dienst.

Die SQL-Vervollständigung verwendet jetzt deklarierte Zelyra-Tabellen und
-Felder. Nach `FROM` und `JOIN` schlägt sie Tabellen vor, nach Tabellenbezügen
oder Aliasen passende Felder. Mehrdeutige Tabellennamen werden ausgelassen.
Die Vorschläge kommen aus der lokalen Compiler-Projektkarte einschließlich
offener Quelltext-Overlays; eine Live-Datenbank wird nicht abgefragt.

Dieses Release führt die Studio-IDE aus 1.2.49 und den reproduzierbaren
Studio-Assets aus 1.2.50 fort. Zelyra 1.3.0 bleibt in Arbeit; dieses Release
erklärt weder die Roadmap noch die Backendparitäts-Gates für abgeschlossen.
