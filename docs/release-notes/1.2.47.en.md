# Zelyra 1.2.47

## Checked host-provided function arguments

When a host starts a Zelyra program through public function execution, the AST
runtime now checks arguments against resolved parameter and generic types
before running preconditions or function code. AST, MIR, and Bytecode report a
type mismatch with the same diagnostic and parameter source span.

Compiler-generated table validators also accept the database representation of
relation keys and `Id` aliases, including optional relations. This exception is
limited to the internal storage bridge; public function parameters retain
their declared Zelyra types.

This closes specific parity cases. AST remains the default and reference
backend; Bytecode remains experimental and opt-in. This release does not claim
complete backend parity.
