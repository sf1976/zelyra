# Zelyra 0.9.5

Zelyra 0.9.5 adds a first-party, local-first application email path and extends
the Laravel Migrator's versioned review findings. This is an experimental
release and is not approved for production.

## Application email

- `mail_queue(to, subject, text, html?)` writes a bounded text/HTML message to
  the existing MariaDB outbox inside the application's database transaction.
- An explicit `zelyra outbox run` handler calls `mail_deliver` to use SMTP.
  SMTP authentication, implicit TLS, STARTTLS, trusted private CA roots,
  hostname verification, and a five-second transport timeout are supported.
- Email requires the `Email` capability, explicit project grants, and an exact
  SMTP hostname in the network allowlist. Plaintext SMTP is restricted to a
  loopback host without credentials and is intended for local test sinks.
- Delivery is at least once. If the relay accepts a message but the worker
  fails before acknowledging the outbox row, the message can be sent twice.
- The first API supports text and HTML alternatives. Named templates, file
  attachments, and PostgreSQL outbox delivery are not included.
- `tests/mail-outbox-e2e.sh` verifies transactional queueing, successful
  authenticated STARTTLS through a trusted local CA, rejection of an untrusted
  CA, retry, MIME content, and SMTP greeting timeout against a loopback sink.

See [Application email](../mail.en.md) and the [environment reference](../env.en.md).

## Laravel Migrator

- Analyzer output now identifies its version and mapping ruleset version.
- Common authorization and policy syntax, tenant-like field names, money and
  aggregate calculations, and file upload/download operations receive explicit
  manual-review findings with source locations.
- The scanner remains static and read-only. It does not run PHP, inspect
  `.env`, establish behavioral parity, or prove that authorization is complete.

See the archived Laravel migration notes.

Independent human product acceptance remains reserved for 1.0.0.
