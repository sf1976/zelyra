# Zelyra 1.0.2

This version fixes the invoice tutorial's Run and database editor flows in
Zelyra Studio. Generated projects use the variable host port
`${ZELYRA_DB_HOST_PORT:-3306}` in their database URL. Studio now resolves it
consistently for schema display, row preview, charts, database creation, and the
launched application. The tutorial tables therefore appear in the database
editor instead of showing “Could not load database schema” and “0 tables.”

On the first click of **Run**, Studio starts the local MariaDB service, retries
temporary startup disconnects, and applies the schema before opening the
preview. Persistent startup or setup failures are reported instead of being
silently ignored. Program output is now 13 px and status text is 12 px; this is
independent of the code editor's font size.

Verification covered `cargo test --workspace`, warning-free Clippy, Studio
browser flows with MariaDB and PostgreSQL, the invoice tutorial with an external
MariaDB, and a real first launch against a fresh Docker Compose database,
including the database editor, row preview, and web application.

Docker Compose v2 or newer is still required. This release does not install
Docker or Compose automatically.
