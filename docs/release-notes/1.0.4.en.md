# Zelyra 1.0.4

Zelyra 1.0.4 fixes invoice tutorial startup when a project is recreated and
improves detection of installed Docker Compose versions.

## Invoice tutorial

Each newly generated invoice tutorial receives its own stable Docker Compose
project name. If the project folder is later recreated, Compose no longer
accidentally reuses an older MariaDB volume with different credentials. For
older invoice tutorials, `setup --all` detects this authentication failure,
starts an isolated database, and retries schema setup. Existing volumes remain
in place and are not changed or deleted.

## Docker Compose

Detection accepts version strings such as `2.40` and reads version output from
both standard output and standard error. Compose v2 is recognized when an
installation reports a short version without a patch number.
