# Zelyra 1.0.1

The invoice tutorial starts with Docker Compose v2 or newer. Zelyra prefers
the Compose plugin and supports modern standalone `docker-compose` binaries.
Python Compose v1 (such as 1.29.2) is rejected before container startup with
an actionable update hint because it crashes on current Docker engines with
`KeyError: 'ContainerConfig'`.

Ubuntu permission failures while writing under `/var/crash` are no longer
classified as denied Docker socket access. Existing project files, `.env`
and database volumes are preserved for retry. After installing the Compose
plugin, verify `docker compose version`, then run `zelyra setup --all` in the
tutorial directory. Regenerating the tutorial is unnecessary. Zelyra does
not install Docker itself.

Local fix-commit validation: 863 passing Rust tests, 2 intentionally ignored
tests, Clippy without warnings, formatting, release metadata, 30 packaging/
gate/SBOM tests and 324 handbook code examples. Against a dedicated MariaDB
test database, repeated schema application, HTTP pages, local theme and
customer create/list passed. Full automatic tutorial startup with MariaDB
and the web container, free-port selection and setup retry also passed. The
application image was built from fix commit `f7cc155` and reports
`zelyra 1.0.1`. Browser checks for desktop, mobile, print and offline styling
passed. Release CI receives additional checks before publication.

This version also fixes Studio Run: the entry point is selected from the
project tree. The previous reference to the nonexistent `files` variable
caused `files is not defined` and also blocked 1.0.0 CI. With the corrected
browser bundle, Studio console output, real web preview and the MariaDB
Studio checks passed.

Language behavior is unchanged. The broader language review follows
publication and receives a separate results report.
