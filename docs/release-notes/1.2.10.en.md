# Zelyra 1.2.10

Zelyra Studio now serializes module-settings saves made by the same Studio
process. When two browser requests start from one settings revision, one save
commits and the stale request receives HTTP 409 instead of silently replacing
it. The settings API continues to reject invalid types, undeclared settings,
symlinks, and oversized files. Tests verify secret values and saved
environment-variable names do not appear in responses.

Package settings remain compiler-checked and package-scoped. Secrets are
referenced from the Zelyra process environment and are not entered or stored as
values in Studio. HostServices remains a versioned Rust embedding interface;
it is not a stable native ABI or package plugin contract. The offline CSV
import/export packages continue to work across the tested AST, MIR, and
Bytecode slices.

Application-served settings pages, writing environment secrets from a web
page, ODBC and Excel adapters, and full MIR/Bytecode parity are not included in
this release. See the [module settings guide](../packages.en.md) and
[HostServices guide](../runtime-host-services.en.md).
