# Zelyra 0.9.6

Zelyra 0.9.6 adds an auditable Laravel migration starting point and a
tenant-scoped notification center. The release remains experimental;
independent human acceptance is planned for 1.0.0.

## Laravel scaffold preview

`zelyra migrate laravel <source> --output <target>` creates a separate Zelyra
project on explicit request. `--report <path>` may be used alongside it or by
itself. The scaffold contains the static analysis report, source locations,
versioned mapping IDs, and clearly marked TODOs. It does not transfer Laravel
business logic and does not read `.env`, databases, or production data. Path
overlap, traversal, symlink escape, and existing targets are rejected; the
result is compiler-checked.

## Notification center

A shared in-app feed is scoped to the active tenant. It provides an unread
count, hides expired and archived entries, and allows notification preferences
to be managed. SMTP is not required. This step does not provide personal read
receipts, a scheduled expiry job, or event-triggered email; that work is planned
for 0.9.7. The new feed is tested against MariaDB.

## Limits

The scaffold preview is not an automatic Laravel port and does not claim
business-logic or security parity. The notification center is not a general
queue. Zelyra remains experimental and is not approved for production use.
Human acceptance is reserved for 1.0.0.
