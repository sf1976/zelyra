# Zelyra 0.9.2 — IDE language services and guided invoice start

Zelyra 0.9.2 is an experimental release and is not approved for production
use. Independent human product and accessibility acceptance remains reserved
for the immutable 1.0.0 candidate.

## Studio language services

Studio now provides contextual help for core language terms, a searchable
action finder, compiler-backed completion, live compiler diagnostics, and a
compiler-derived project map. F12 opens a saved definition in the active or a
directly imported source file. Shift+F12 finds exact lexical identifier
occurrences in saved `.zyl` files. Occurrence results are not scope-aware
semantic references; unsupported or ambiguous project relationships are not
guessed.

The explicit **Run** action executes `main.zyl` with a 15-second limit and
64-KiB output limit per stream. Recognized environment and local `.env` secret
values are redacted before display. The program is not run automatically, and
Studio does not provide interactive stdin.

The local editor session remains loopback-only and guarded by its session token
and same-origin checks. The browser opens automatically on desktop; use
`zelyra editor --no-open` on headless systems. Starting Studio does not start a
database or the application.

## Invoice tutorial

`zelyra --tutorial invoice` now starts the local MariaDB and web Compose
application and applies the schema as part of the guided setup. The generated
web service obtains its database URL from project setup, so beginners need not
configure `DATABASE_URL` manually. `--no-start` creates the files without
starting Docker. The example calculates net, 19% VAT, and gross and provides a
print-ready view that the browser can save as PDF; this is a learning example,
not a native PDF engine or a legal-compliance claim.

## Limits and acceptance

Studio's project map and language tools are limited to their documented
compiler-backed subsets. Search results are lexical, type inference and full
semantic references are not included, and a displayed relation does not imply
authorization. Database introspection and generated project flows retain their
published backend limits. The final manual accessibility review and all
independent human product acceptance remain reserved for 1.0.0.
