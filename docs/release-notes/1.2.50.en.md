# Zelyra 1.2.50

This maintenance release synchronizes the Studio source modules with the
shipped browser assets. Menus, the welcome screen, terminal, and database
record actions can now be reproduced from `editor/src`.

Studio integration checks cover MariaDB and PostgreSQL projects. The current
Zelyra REPL supports sandbox transactions only with MariaDB/MySQL; for
PostgreSQL, Studio displays the CLI error. Database Studio features are not
affected by this REPL limitation.
