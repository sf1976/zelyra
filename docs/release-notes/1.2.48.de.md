# Zelyra 1.2.48

## Zusammengefasste Array-Index-Inkremente im Bytecode

Für `mutable_array[index] += <Int-Literal>` kann der Bytecode-Compiler eine
verifiergeprüfte Einzelinstruktion erzeugen, die den Index prüft und das Array
aktualisiert. Das Quellschrittbudget wird erst nach der Bereichsprüfung
belastet; damit bleibt die Fehlerreihenfolge von AST und MIR erhalten. Andere
rechte Ausdrücke verwenden weiterhin den allgemeinen geprüften Ablauf.

Das versionierte Bytecode-Artefaktformat steigt auf v30. Dieses Format ist
experimentell und mit früheren Bytecode-Artefakten inkompatibel; AST bleibt
Referenz- und Standardbackend.

Ein gepinnter Vergleich auf demselben Rechner mit 20.000 Integern und 100.000
Indexupdates maß einen Bytecode-Median von 33,77 ms vor und 29,45 ms nach der
Änderung (12,8 % niedriger). Das ist ein Ergebnis für eine einzelne Arbeitslast
und keine allgemeine Leistungsaussage.
