# Zelyra 1.2.53

## Zelyra-aware editing in Studio

Studio now pairs brackets and quotation marks while you type and indents Zelyra
blocks with four spaces. Tab indents the current line or selection, and
Shift+Tab moves it back. Indentation follows Zelyra block structure and ignores
braces inside comments and strings, so normal typing stays predictable while
editing incomplete code.

These editor changes add to Studio's Zelyra-specific completion, compiler
context, SQL tools, database browser, and integrated Zelyra terminal. Zelyra
1.3.0 remains in active development; this patch release does not complete the
broader Studio or language roadmap.
