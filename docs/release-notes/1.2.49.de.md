# Zelyra 1.2.49

## Zelyra Studio: IDE für die Sprache

Die Menüleiste bündelt Datei-, Bearbeitungs-, Ansichts-, Ausführungs-,
Datenbank- und Hilfeaktionen. Das optionale integrierte Terminal startet die
Zelyra-Konsole direkt im Projektordner. Es führt keine Betriebssystem-Shell
aus; Eingabe und Ausgabe sind auf eine lokale, begrenzte Sitzung beschränkt.

Vervollständigungen nutzen aufgelöste Symbole des aktiven Moduls und seiner
Imports. Importpfade schlagen passende Zelyra-Dateien vor; nach einem Import
können exportierte Namen im Alias-Namensraum gewählt werden. SQL-Blöcke bieten
passende Schlüsselwörter und deklarierte Tabellen. An passenden Stellen zeigt
Studio Startbausteine, die erst nach Auswahl in den Quelltext gelangen.

Der Datenbrowser kann Datensätze in deklarierten Tabellen mit passendem
Live-Schema anlegen, bearbeiten und löschen. Schreibvorgänge erfordern eine
Bestätigung, verwenden gebundene Parameter und verlangen für Änderung und
Löschen einen Primärschlüssel.
