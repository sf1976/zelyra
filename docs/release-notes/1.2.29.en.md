# Zelyra 1.2.29 — secure file uploads

Zelyra 1.2.29 adds bounded multipart uploads to checked forms. A form can
declare a file field with a maximum size and a finite allowed media-type list.
The server checks the file signature and size, stores accepted content outside
the public directory under an opaque tenant-scoped reference, and can serve it
through an authenticated, permission-checked CRUD download route.

The upload path preserves route authorization, CSRF validation, form
validation, database parameter binding, and transaction cleanup. It supports
one file per field and PDF, PNG, or JPEG signatures. Replacing a file removes
the prior blob only after the database transaction commits. Permanent record
deletion removes a blob only when no declared `FileRef` column still references
it. Soft deletion retains the file.

`zelyra files cleanup` previews old, unreferenced files and abandoned staging
pairs. Deletion requires explicit `--apply --maintenance-window`; the command
rechecks database references while holding an exclusive local maintenance
lock. Upload-enabled servers hold the corresponding shared lock while running.
`zelyra files backup` and `zelyra files restore` create and verify a private
file-storage snapshot with SHA-256 checksums.

## Limits

Managed storage creation currently fails closed on non-Unix platforms because
private ACL support is not implemented there. The upload formats are limited to
PDF, PNG, and JPEG, with one file per field. Signature checks do not sanitize
documents or scan for malware. A process crash between filesystem publication
and database commit can leave an unreachable orphan; explicit reference-aware
cleanup handles it. File-storage backups exclude database contents, project
configuration, and secrets; back these up separately with the Zelyra servers
stopped. Whole-application coordinated backup is not provided. The Laravel
importer classifies unsupported upload workflows for manual migration; this
release does not import arbitrary Laravel upload behavior. PostgreSQL upload
storage has not passed the complete lifecycle end-to-end suite and is not
claimed as supported.
