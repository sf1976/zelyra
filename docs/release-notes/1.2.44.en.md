# Zelyra 1.2.44

## Live schema evidence for Laravel migration analysis

`zelyra import laravel analyze --inspect-database` can compare generated
Zelyra schema candidates with metadata from an explicitly configured live
database. The inspection is read-only: it reads catalog metadata, not
application rows, and it does not apply schema changes.

Each raw difference remains visible alongside a cautious classification,
evidence, rationale, and a suggested review step. A classification is not a
compatibility guarantee or an automatic migration. Unverified or ambiguous
differences remain for human review.

The analyzer was exercised against `/opt/siedelmann-laravel/app`: 80 schema
candidates were compared with 89 live tables and 1,294 columns. The report
contained 403 differences. This describes that inspected project and is not a
claim that its application behavior has been imported.

Reusable packages are intended for recurring business capabilities that are
useful across projects. One-off exceptions remain explicit application code;
they are not turned into packages or hidden importer rules.
