# Zelyra 1.2.33

Zelyra 1.2.33 improves the experimental MIR and bytecode execution paths while
keeping the AST interpreter as the default.

## Changes

- Source-level `--max-steps` accounting is aligned across the supported AST,
  MIR, and bytecode paths. The VM retains its separate instruction safety cap.
- Differential tests compare AST, MIR, and encoded/decoded bytecode for one
  transaction containing a SQL audit insert and one queued email with a PDF
  attachment. They check transaction mode, statement order, parameters, and
  attachment bytes and metadata.
- AST remains the default. MIR and bytecode require explicit experimental
  backend selection.

## Limits

These checks cover specific supported execution slices. They do not establish
general backend parity, multiple queued messages, transaction rollback parity,
or equivalent behavior for every host effect. The bytecode backend is not the
default runtime.
