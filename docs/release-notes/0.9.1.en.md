# Zelyra 0.9.1 — IDE foundation, invoice printing, and comments

Zelyra 0.9.1 is an experimental release and is not approved for production
use. Independent human product acceptance remains reserved for the immutable
1.0.0 candidate.

## Studio

The local editor now keeps its session when the tab reloads. It removes the
session token from the address bar and retains it only in that tab's
`sessionStorage`. Edits show as unsaved, `Ctrl+S` saves the current editor
content, and compiler diagnostics appear in the Problems panel. Automated
Chromium coverage exercises the unsaved-work warning, save, diagnostics, and
restart.

## Invoice tutorial

The example calculates net, 19% VAT, and gross from linked invoice lines.
`/invoices/{invoice_number}/print` provides a print-ready view that the browser
can save as PDF. The 19% rate is a learning assumption for the German example;
Zelyra does not generate a legally compliant invoice or include a native PDF
engine.

## Comments

`#` begins a single-line comment. A standalone `##` line begins or ends a
non-nesting block comment. Existing `//` comments remain compatible.

## Limits and acceptance

Version 0.9.1 is experimental and not approved for production. Studio security
boundaries and exact database workflows are documented in the
[database support matrix](../database-support.en.md). Independent human product
acceptance remains planned for 1.0.0.
