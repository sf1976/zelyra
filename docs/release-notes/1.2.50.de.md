# Zelyra 1.2.50

Diese Wartungsversion gleicht die Studio-Quellmodule mit den ausgelieferten
Browser-Assets ab. Änderungen an Menüs, Startansicht, Terminal und
Datenbankaktionen lassen sich damit reproduzierbar aus `editor/src` erzeugen.

Die Studio-Prüfung deckt MariaDB- und PostgreSQL-Projekte ab. Die aktuelle
Zelyra-REPL unterstützt Sandbox-Transaktionen nur für MariaDB/MySQL; bei
PostgreSQL zeigt Studio den CLI-Fehler an. Die Datenbankfunktionen im
Datenbank-Studio bleiben davon unberührt.
