# Zelyra 1.2.51

## Zelyra Studio reads the project with the compiler

Studio's welcome page reads the local compiler project map and summarizes
recognized modules, data models, web surfaces, and SQL queries. It recommends a
next action from the project context and marks incomplete analysis clearly.
The overview does not change source files and does not require an AI or cloud
service.

SQL completion now uses declared Zelyra tables and fields. It suggests tables
after `FROM` and `JOIN`, fields after table references or aliases, and omits
ambiguous table names. Completion uses the local compiler project map and open
source overlays; it does not query a live database.

This release continues the 1.2.49 Studio IDE and 1.2.50 reproducible-asset work.
Zelyra 1.3.0 remains in progress; this release does not declare its roadmap or
backend-parity gates complete.
