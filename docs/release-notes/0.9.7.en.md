# Zelyra 0.9.7

Zelyra 0.9.7 improves the invoice tutorial for a complete desktop workflow and
makes the Studio project map more informative. The release remains experimental;
independent human acceptance is reserved for 1.0.0.

## Invoice tutorial

The multi-file tutorial shows customer and invoice metrics from stored records
and guides the user through customers, items, invoices, and print output. Tabler
Core 1.6.1 is served locally as the CSS baseline. It requests no CDN or external
JavaScript. The dashboard and generated CRUD paths are checked for desktop,
narrow viewports, and print. Monetary totals include draft records and therefore
do not represent posted revenue.

## Studio project map

Page and CRUD layouts resolve within their module or through explicitly
imported public views. Table views appear as data nodes. Ambiguous, unresolved,
or analysis-limited relationships receive stable diagnostic codes. Unknown
relationships are not guessed.

## Limits

Personal read receipts and recipient authorization in the notification center,
along with safe mail templates and attachments, moved to the technical 0.9.8
milestone. The shared `read_at` field from 0.9.6 is not presented as a personal
read receipt. Zelyra remains experimental and is not approved for production
use. Human acceptance is reserved for 1.0.0.
