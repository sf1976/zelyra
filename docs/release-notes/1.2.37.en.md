# Zelyra 1.2.37

The reusable CSV importer now supports explicitly declared conversions to
text, integer, and Boolean. Results remain tagged `CsvValue` values; invalid
cells report their CSV row and target column. The importer does not infer
field types from a database schema and does not write to the database.
Decimal, date, and time conversion remain open.

MIR also normalizes qualified enum variants during lowering. Imported package
enums now use the same matching behavior across AST, MIR, and Bytecode.
