# Zelyra 1.2.43

Zelyra's Laravel website importer can now wire a small, strictly verified
subset of translated static Blade presentations to native Zelyra pages.

## Static presentation routes

The generator emits a Zelyra `page` only when all of these conditions hold:

- The Laravel route is a literal, ungrouped `GET` route with no middleware.
- Its closure has no parameters.
- Its only statement returns one literal `view('...')` reference.
- That exact view has already passed the existing static presentation
  translator.
- The route path is not occupied by another generated route and is not
  ambiguous in the source inventory.

The generated page uses the generated Zelyra layout when available, otherwise
the local public shell. Route-to-view provenance is included in
`GENERATION_SELECTION.json`, `VIEW_TRANSLATIONS.json`, and
`SOURCE_FILE_PLAN.json`. PHP is not executed.

This is a narrow static page slice. It does not translate arbitrary Blade,
dynamic values, shared partials, protected routes, controller behavior, or
application workflows. A clean scaffold compiler check does not establish
behavioral equivalence with Laravel.

## Verification

The release is gated by compiler-checked synthetic route fixtures, the source
inventory and scaffold checks against `/opt/siedelmann-laravel/app`, and the
workspace and release CI. The real integration project currently has no page
matching this narrow route-and-view shape.
