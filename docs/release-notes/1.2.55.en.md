# Zelyra 1.2.55

## A more polished Zelyra Studio and UI foundation

Generated applications now use the CSS 1.1.0 design-system bundle. The
refreshed defaults improve CRUD cards, forms, tables, navigation, and narrow
screen layouts. Documented tokens provide project-level light and dark theme
customization, and reduced-motion preferences are respected.

Studio adds a dedicated Project menu for reviewing capabilities and paths and
for opening package and module settings. Completion offers public declarations
after an explicitly imported module namespace. Runtime settings can select MIR
or Bytecode for console programs as an experiment. AST remains the default;
web previews remain AST-only, and experimental backends still fail closed for
unsupported constructs.
