# Zelyra 1.0.2

Diese Version behebt den Start und den Datenbankeditor des Invoice-Tutorials in
Zelyra Studio. Die erzeugte Datenbankadresse enthält den variablen Host-Port
`${ZELYRA_DB_HOST_PORT:-3306}`. Studio löst ihn nun für Schemaanzeige,
Datensatzvorschau, Diagramme, Datenbankanlage und die gestartete Anwendung
einheitlich auf. Dadurch erscheinen die Tutorialtabellen im Datenbankeditor
statt „Datenbankschema konnte nicht geladen werden“ und „0 Tabellen“.

Beim ersten Klick auf **Starten** startet Studio den lokalen MariaDB-Dienst,
wartet bei vorübergehenden Startabbrüchen erneut und richtet das Schema ein,
bevor es die Vorschau öffnet. Dauerhafte Fehler beim Starten oder Einrichten
werden angezeigt, statt im Hintergrund ignoriert zu werden. Die Programmausgabe
ist jetzt 13 px und der Status 12 px groß; die Schriftgröße des Code-Editors
bleibt davon unabhängig.

Integer-Bereichsschleifen unterstützen jetzt optionale Schrittweiten, zum
Beispiel `for i in 1..21 step 2`. Das Ende bleibt exklusiv; negative
Schrittweiten zählen rückwärts. Die Schrittweite muss den Typ `Int` haben und
darf nicht null sein. `range(start, end, step)` erzeugt dieselbe Folge als
Array.

Verifiziert wurden `cargo test --workspace`, Clippy ohne Warnungen,
Studio-Browserabläufe mit MariaDB und PostgreSQL, das Invoice-Tutorial mit
externer MariaDB sowie ein echter erster Start aus einer frischen Docker-
Compose-Datenbank einschließlich Datenbankeditor, Datensatzvorschau und
Webanwendung.

Docker Compose v2 oder neuer muss weiterhin installiert sein. Dieses Release
installiert Docker oder Compose nicht automatisch.
