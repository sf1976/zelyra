# Zelyra 1.2.24

Generierte CRUD-Anlegen- und Bearbeiten-Formulare können jetzt mehrere direkte
`has_many`-Sammlungen desselben Elternsatzes verwalten. Jede Sammlung erscheint
in einem eigenen Abschnitt, hat eine unabhängige Zeilenanzahl und verwendet
eigene Feld- und Zeilenaktionsnamen.

Zelyra validiert alle Sammlungen vor dem Schreiben. Elterndaten, alle
Kindzeilen und deklarierte Aggregatberechnungen werden in einer
Datenbanktransaktion gespeichert. Eine ungültige Sammlung oder ein
Datenbankfehler rollt den gesamten Vorgang zurück. Beim Bearbeiten werden die
Kindzeilen des gewählten Elternsatzes gesperrt und gelesen; ersetzt werden nur
dessen Zeilen. Die Mandantenidentität stammt weiterhin aus dem geprüften
Anfragekontext.

Das Limit von 50 Zeilen pro Sammlung bleibt bestehen. Eine Kindtabelle darf
nur einmal an eine CRUD-Ressource gebunden werden; mehrere Sammlungen dürfen
dasselbe Aggregatziel nicht mehrdeutig beschreiben.

Ein compilergeprüftes Rechnungsbeispiel mit Positionen, Anhängen und
Aggregaten steht in
[`examples/multiple_children/main.zyl`](../../examples/multiple_children/main.zyl).
