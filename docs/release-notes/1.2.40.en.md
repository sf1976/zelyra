# Zelyra 1.2.40

Zelyra adds a constrained `public_token` form primitive for public
confirmation routes on tenant-scoped records. The compiler requires one
captured token, a tenant-scoped table, a globally unique required `String(64)`
hash field, a nullable `Timestamp?` result field, and a confirmation-only
action. Arbitrary caller SQL and custom handlers are not accepted.

At runtime, Zelyra hashes the captured bearer token, resolves its matching
record, and updates only that record using both its primary key and tenant key
inside a transaction. CSRF protection remains enabled. Token response pages
are marked `no-store`, and repeated requests keep the original confirmation
timestamp.

The Laravel website importer uses this primitive for the statically verified,
tenant-scoped unsubscribe workflow in `/opt/siedelmann-laravel/app`. Generated
components explicitly import their dependencies. This is one reviewed
workflow mapping; it does not migrate the Laravel website or resolve the
remaining importer findings.

## Installation

Download the Linux `.tar.gz` or Windows `.zip` from the GitHub release and
verify its adjacent `.sha256` file before extracting it. The runtime does not
require npm.
