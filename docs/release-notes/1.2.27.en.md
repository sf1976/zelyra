# Zelyra 1.2.27

Zelyra 1.2.27 adds the foundation for importing selected behavior from a
Laravel-built website into native Zelyra projects.

## Included

- Read-only-first analysis of routes, controllers, services, models,
  migrations, Blade views/layouts, assets, and optional live database schema
  metadata.
- Explicit generation selection with `--table <name>` or `--all-supported`.
- Generated schema and narrow pure model/service candidates, bounded view and
  public asset candidates, plus reusable native authentication modules.
- Tenant identity mapping for resolved conventional membership pivots and
  direct `tenants.user_id` ownership.
- Compiler checks for generated projects and a regression test proving that a
  generated authentication package can be copied into a separate consumer
  project, locked, checked, and routed.

## Limits

This release does not import Laravel's complete website behavior. Route
handlers, arbitrary controller workflows, policies, Blade rendering details,
active/default tenant selection, and full deployment configuration remain
unmigrated. The importer does not execute PHP or read application rows. Live
schema inspection requires an explicit request and only reads database
metadata. Generated bundles report incomplete deployment where runtime effects
or configuration are not included. The acceptance project is
`/opt/siedelmann-laravel/app`; broader behavior coverage remains on the roadmap.

## Verification

The merged importer PR passed workspace tests, Clippy, the full generated
Docker project E2E, the invoice tutorial E2E, database integration matrices
for MariaDB 10.11, 11.4, 11.8, 12.3, and MySQL 8.4, release artifact builds,
and the remaining CI checks.
