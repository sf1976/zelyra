## 1.2.28 release completion — 2026-10-20

Version 1.2.28 includes typed transactional CRUD actions and the hardened REPL additions. Actions use compiler-checked `row`/`session` contexts, guards under a row lock, explicit capabilities, and one request transaction for business writes and audit. MariaDB and PostgreSQL HTTP E2Es cover successful and concurrent execution plus rollback; MariaDB also verifies a real PDF queued in the outbox without SMTP delivery.

The REPL sandbox rejects DDL, transaction-control, and session-control statements that could bypass rollback. Grant denial, rollback, and explicit commit are also tested. `:schema` displays invariant messages and source positions. Limitations: REPL SQL still requires the aggregate `Database` grant; a read-only grant alone is insufficient. The REPL backend supports AST; bytecode execution in the REPL is not implemented. The broader permission/capability matrix remains follow-up work.

Release gates ran on the published revision; release workflows create and verify the platform archives.
