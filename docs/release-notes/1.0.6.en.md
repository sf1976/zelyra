# Zelyra 1.0.6

**Released:** 2026-10-14 · **Language compatibility:** `0.1`

Zelyra 1.0.6 adds Zelyra UI, a locally delivered, compiler-checked design
system for business applications. It updates generated CRUD pages, starter
projects, Studio's property inspector, and the invoice tutorial to use the same
component system.

## Zelyra UI

- Adds 55 typed components for page layouts, navigation, status, forms,
  tables, charts, print views, and accessible interactions through the
  explicitly imported `zelyra/ui` module.
- Adds a versioned CSS and JavaScript bundle embedded in Zelyra. Applications
  need no npm install, frontend build, CDN, external fonts, or network request
  to render the framework.
- Gives generated forms and CRUD pages the same responsive page shell,
  fields, actions, tables, validation feedback, empty states, and layout styles
  as hand-written views. Existing escaping, CSRF, permissions, server-side
  validation, and parameterized SQL remain in force.
- Adds compiler-checked `default`, `success`, `warning`, and `danger` appearance
  values to supported components and declarative fields. Presentation remains
  separate from actual validation state.
- Adds light/dark and system themes, comfort/compact density, print rules, and
  safe project theme overrides. `ZELYRA_UI_STYLESHEET` selects the built-in
  default, the bundled Tabler stylesheet, or an allowed project-relative CSS
  replacement; the project theme remains an override. Remote CSS and unsafe
  project paths are rejected.
- Adds Studio property information for UI components and a compiler-backed
  appearance editor.

## Invoice tutorial, charts, and print

The invoice tutorial now uses the Zelyra UI shell, business-focused create and
overview pages, and a component gallery. It includes text-equivalent bar,
line, and donut charts and a print stylesheet for invoices. The print action
uses the browser's print dialog, where a user can save a PDF. `EmailLink` opens
the local mail client with a prefilled recipient, subject, and invoice number;
the saved PDF must be attached manually.

## Boundaries

Zelyra 1.0.6 does not include its own server-side PDF renderer or automatic
email attachment delivery. The existing transactional mail outbox supports
text and HTML. The bundled Tabler option replaces the stylesheet; it does not
translate legacy Tabler classes into Zelyra UI components, and full Tabler
compatibility is not claimed. Arbitrary HTML, CSS classes, and project CSS are
not generally statically checked.

## Verification

The release candidate is checked by the Rust workspace tests, Clippy and
Rustdoc with warnings denied, Studio metadata and editor build/audit checks,
UI asset and handbook validators, release artifact smoke checks, and browser
coverage for the invoice tutorial and Studio. The release workflow builds and
verifies Linux and Windows x86_64 archives, checksums and SBOMs, attests the
artifacts, and publishes only after those jobs succeed.
