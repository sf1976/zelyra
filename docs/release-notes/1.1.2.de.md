# Zelyra 1.1.2

Zelyra 1.1.2 entfernt den experimentellen Laravel-Analysator und Gerüstbefehl (`zelyra migrate laravel`). Quellcode, Migrationsberichte und bisherige Anleitungen sind nicht mehr Bestandteil des Projekts. Ein separates privates Archiv bewahrt die bisherige Arbeit für eine mögliche spätere Verwendung.

Dieses Release importiert keine Laravel-Anwendungen. Historische Release-Notizen bleiben als Dokumentation früherer Versionen erhalten.
