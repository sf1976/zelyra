# Zelyra 1.0.1

Das Rechnungstutorial startet mit Docker Compose v2 oder neuer. Zelyra
bevorzugt das Compose-Plugin und unterstützt moderne eigenständige
`docker-compose`-Programme. Python Compose v1 (etwa 1.29.2) wird vor dem
Containerstart mit einem konkreten Update-Hinweis abgewiesen, weil es auf
aktuellen Docker-Engines mit `KeyError: 'ContainerConfig'` abstürzt.

Ein Ubuntu-Berechtigungsfehler beim Schreiben unter `/var/crash` wird nicht
mehr als fehlender Docker-Socket-Zugriff eingeordnet. Vorhandene
Projektdateien, `.env` und Datenbank-Volumes bleiben für die Wiederholung
erhalten. Nach Installation des Compose-Plugins `docker compose version`
prüfen und im Tutorialordner `zelyra setup --all` ausführen. Das Tutorial
muss nicht erneut erzeugt werden. Zelyra installiert Docker nicht selbst.

Lokale Prüfung des Fix-Commits: 863 erfolgreiche Rust-Tests, 2 bewusst
ignorierte Tests, Clippy ohne Warnungen, Formatierung, Release-Metadaten,
30 Paket-/Gate-/SBOM-Tests und 324 Handbuch-Codebeispiele. Mit einer eigenen
MariaDB-Testdatenbank bestanden zweimalige Schema-Anwendung, HTTP-Seiten,
lokales Theme und Kunden-Erstellung samt Listenanzeige. Auch der vollständige automatische
Tutorialstart mit MariaDB und Webcontainer, freie Portauswahl und Setup-
Wiederholung bestanden. Das Anwendungsimage wurde aus Fix-Commit `f7cc155`
gebaut und meldet `zelyra 1.0.1`. Browserprüfungen für Desktop, Mobilansicht,
Druck und Offline-Styling bestanden. Release-CI wird vor Veröffentlichung
zusätzlich geprüft.

Der Sprachumfang bleibt unverändert. Die breitere Sprachprüfung folgt nach
der Veröffentlichung und erhält einen eigenen Ergebnisbericht.
