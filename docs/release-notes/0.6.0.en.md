# Zelyra 0.6.0 release candidate

Zelyra 0.6.0 adds route and database overviews, plus a bounded PostgreSQL runtime
slice. This candidate is for technical verification and remains experimental.
It is not a production approval or evidence of independent human acceptance;
that acceptance is reserved for 1.0.0.

## Route inventory

Run `zelyra routes <entry.zyl>` to list recognized page, API, form, tableview,
CRUD, and authentication routes with their HTTP method, path, and source
location. `--format json` emits machine-readable output. Overlapping routes
using the same HTTP method fail with `E-ROUTE-001`; the diagnostic identifies
the conflicting source locations. The inventory includes imported and generated
resource routes.

## Database map

Run `zelyra db map <file.zyl>` for a read-only overview of declared tables by
source module and comparison with live tables, columns, and foreign keys.
`--format json` emits machine-readable output. Module ownership is an advisory
inference for navigation. The command does not modify schemas and does not
create authorization rules. Backend-specific inspection limitations remain
visible; existing databases are not renamed or reorganized.

## Bounded PostgreSQL runtime

The runtime has a native pooled PostgreSQL path for direct parameterized SQL and
transaction batches. It supports the tested PostgreSQL 16 workflow and a bounded
set of scalar result types. PostgreSQL schema inspection and generated web/CRUD
paths still use the existing external tooling and are not covered by this native
runtime slice. This release does not claim complete PostgreSQL parity, support
for every PostgreSQL type, or compatibility with untested server versions.

## Upgrade and support notes

Zelyra 0.6.0 is experimental and not approved for production use. MariaDB remains
the established tested server path. MySQL Server support is not claimed. Review
the [database compatibility guide](../database-compatibility.en.md) and the
[0.6.0 roadmap](../release-plans/0.6.0.en.md) before adopting database features.

Independent human acceptance remains scheduled for the immutable 1.0.0 release
candidate. The final technical readiness milestone is 0.99.0.
