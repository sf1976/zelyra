# Zelyra 1.2.38

The standard library now provides `parse_decimal(text) -> Result<Decimal, String>`. It parses exact base-10 values with up to nine fractional digits directly into Zelyra's Decimal representation. It does not use Float; whitespace, a leading plus, exponent notation, and overflow are rejected through `Err`.

The reusable `csv_import` package adds an explicit `Decimal` mapping and tagged `CsvValue::Decimal`. Conversion is selected by the caller, reports invalid row and target column, and does not infer types from database schemas or write to a database.

Date/time conversion, database preview/apply, transactional imports, ODBC, PDF output, and Excel-compatible export remain open module work.

## Install

Download the Linux `.tar.gz` or Windows `.zip` below and verify its adjacent
`.sha256` file. Extract the archive and place `zelyra` (or `zelyra.exe`) in a
directory on `PATH`. The archive includes the standalone CLI and license/readme
files; no npm runtime is required.
