# Zelyra 1.0.4

Zelyra 1.0.4 korrigiert den Start des Rechnungstutorials bei erneut angelegten
Projekten und verbessert die Erkennung installierter Docker-Compose-Versionen.

## Rechnungstutorial

Jedes neu erzeugte Rechnungstutorial erhält einen eigenen stabilen
Docker-Compose-Projektnamen. Wird der Projektordner später neu angelegt,
verwendet Docker Compose dadurch nicht mehr versehentlich ein älteres
MariaDB-Volume mit anderen Zugangsdaten. Bei älteren Rechnungstutorials erkennt
`setup --all` den Authentifizierungsfehler, startet eine isolierte Datenbank und
wiederholt das Schema-Setup. Vorhandene Volumes bleiben erhalten und werden
weder gelöscht noch verändert.

## Docker Compose

Die Erkennung akzeptiert Versionsangaben wie `2.40` und wertet die Ausgabe auf
Standardausgabe und Standardfehler aus. Compose v2 wird damit auch dann erkannt,
wenn die Installation die Kurzversion ohne Patchnummer meldet.
