# Zelyra 1.2.45

## Reusable billing calculation

The local `billing` package provides `calculate_line_amounts` for one invoice
line and returns typed net, tax, and gross amounts. Callers explicitly choose
the tax fraction, Decimal scale, and rounding mode.

The function rounds net first, rounds tax calculated from that net, then
calculates gross as net plus tax. It assumes no jurisdictional tax rules,
currency, invoice numbering, posting, or other workflow. Decimal intermediate
values can have up to nine fractional digits. Applications with different
rounding or document-level aggregation rules must state and verify those rules
in application code.

The runnable demo checks the calculation on AST, MIR, and Bytecode. This
example-level differential test does not establish full backend parity or make
Bytecode the default.
