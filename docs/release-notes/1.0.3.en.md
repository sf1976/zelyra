# Zelyra 1.0.3

This release delivers the largest standard library and developer ergonomics expansion in Zelyra's history. With over 55 new built-in functions, the forward pipeline operator `|>`, native `else if` branching cascades, and robust Studio database management, developing business applications in Zelyra is more intuitive, productive, and reliable.

## 1. Expanded Standard Library (55+ Functions)

All stateless standard functions are directly callable without capabilities and support the new pipeline operator `|>`. Functions interacting with external system resources (such as random numbers, file system, or clock) require their respective capability as before:

1. **Mathematics & Numerics:** `abs`, `min`, `max`, `clamp`, `sqrt`, `pow`, `floor`, `ceil`, `round`
2. **Strings & Text Processing:** `len(String)`, `text_to_lower`, `text_to_upper`, `text_starts_with`, `text_ends_with`, `text_replace`, `text_split` (alias: `split`), `text_pad_left`, `text_pad_right`, `text_index_of`, `text_repeat`, `text_is_empty`, `text_is_blank`, `text_capitalize`, `text_substring`, `text_trim_start`, `text_trim_end`
3. **Arrays & Collections:** `sort`, `sort_desc`, `reverse`, `slice`, `concat`, `join`, `unique` (alias: `dedup`), `array_sum`, `avg`, `min_of`, `max_of`, `chunk`, `flatten`, `zip`
4. **Sets:** `set_union`, `set_intersection`, `set_difference`
5. **Maps & Iteration:** `get_or`, `has_key`, `map_remove`, `map_merge`, `entries` (returns key-value 2-tuples for direct loops `for (k, v) in entries(map)`)
6. **Date & Calendar Arithmetic:** `date_add_days`, `date_diff_days`, `is_before`, `is_after`
7. **Control Flow & Error Handling:** `is_ok`, `is_err`, `is_some`, `is_none`, `unwrap_or`, `panic`
8. **Type Conversions & Parsing:** `to_string`, `parse_int`, `parse_float`, `to_int`, `to_float`, `parse_bool`
9. **Security & Web Encodings:** `hash_sha256`, `base64_encode`, `base64_decode`, `url_encode`, `url_decode`, `uuid_v4` (`uses Random`)
10. **Paths & Filesystem:** `path_join`, `path_filename`, `path_extension`, `path_dir` (pure path operations without capability); `file_exists`, `dir_exists`, `file_size` (`uses FileSystem`)

## 2. Forward Pipeline Operator `|>`

Zelyra now supports the forward pipeline operator `|>`. Expressions flow from left to right through transformation chains without deeply nested parenthesized function calls:

~~~zelyra
cleaned = "  customer@example.com  "
    |> text_trim()
    |> text_to_lower()
~~~

## 3. Flat `else if` Branching

Conditional branches now support flat `else if` chains without mandatory nested blocks:

~~~zelyra
if status == 1 {
    return "Active"
} else if status == 2 {
    return "Paused"
} else {
    return "Inactive"
}
~~~

## 4. Zelyra Studio & Database Robustness

- **Declared Schema Fallback when Database is Offline:** If the local MariaDB service is not yet started or the database is not created, Studio no longer crashes with a 502 error. All tables declared in Zelyra source code (`main.zyl` and imported modules) are listed as *declared in source · missing in live DB*.
- **Automatic Schema Initialization:** When creating the database in Studio, the local Docker Compose service is started if needed, and the schema is initialized immediately.

## 5. Formatter & Verification

- `zelyra fmt` formats pipeline operators and `else if` blocks consistently and idempotently.
- Verified across 216 CLI tests, 158 runtime tests, workspace tests, and 329 handbook code examples.
