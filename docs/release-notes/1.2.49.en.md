# Zelyra 1.2.49

## Zelyra Studio: an IDE for the language

The application menu groups file, editing, view, run, database, and help
actions. The optional integrated terminal starts the Zelyra console in the
project folder. It does not run an operating-system shell; input and output
stay within a bounded local session.

Completion uses resolved symbols from the active module and its imports.
Import paths suggest matching Zelyra files; after an import, exported names can
be selected through the imported alias. SQL blocks offer relevant keywords
and declared tables. Studio offers starter blocks at suitable locations, and
inserts them only after selection.

The record browser can create, edit, and delete records in declared tables
that match the live schema. Writes require confirmation, use bound parameters,
and require a primary key for updates and deletes.
