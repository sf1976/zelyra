# Zelyra 1.2.54

## Importhilfe im Zelyra Studio

Nach `import "` schlägt Studio passende `.zyl`-Quelldateien aus dem aktuellen
Projekt vor. Die gerade bearbeitete Datei, doppelte Imports, andere Dateitypen
und Kommentartext werden ausgelassen. Nach Vergabe eines Alias setzt die
bestehende compilerbewusste Vervollständigung mit den öffentlichen
Deklarationen des Moduls fort. Das macht den Importablauf leichter auffindbar,
ohne Compilerprüfungen zu lockern.

Dieses Release aktualisiert außerdem die transitive Abhängigkeit `ctutils` auf
0.4.5 als Reaktion auf
[RUSTSEC-2026-0385](https://rustsec.org/advisories/RUSTSEC-2026-0385.html).
