# Zelyra 1.2.52

## Zelyra Studio understands what you are writing

Studio now uses compiler-resolved Zelyra information to guide code as it is
written. While editing a function call, it shows the resolved signature and
highlights the active argument. This also works with public imported functions.

After `receiver.`, completion can offer fields from the inferred record type,
including public records from imported modules and concrete generic field
types. If the type cannot be resolved, Studio does not invent members. Normal
compiler checks remain authoritative.

After an imported `alias::`, completion is scoped to that module's public
declarations and responds to unsaved import edits in the current buffer.

The optional AI suggestion action remains disabled by default. It sends only
the selected source and instruction after an explicit confirmation and never
applies generated code automatically. It supports HTTPS services and local
loopback HTTP with bounded input and output.

These improvements make Studio's help specific to Zelyra's compiler, modules,
types, and SQL-oriented workflow. Zelyra 1.3.0 remains in active development;
this release does not mark its broader roadmap complete.
