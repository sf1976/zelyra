# Zelyra 1.2.25

Zelyra erhält native Datenbankkonsole und direkte Abfragebefehle.

`zelyra db console [main.zyl]` löst die konfigurierte Datenbankverbindung über
`ZELYRA_DATABASE_<NAME>_URL` oder `DATABASE_URL` auf, einschließlich der
Projekt-`.env`, und startet anschließend den installierten MariaDB-/MySQL- oder
PostgreSQL-Client. Passwörter werden über `MYSQL_PWD` oder `PGPASSWORD`, nicht
als Kommandozeilenargument übergeben. Der Client muss auf dem Host installiert
sein.

`zelyra db query main.zyl "SELECT id, email FROM customers" --format table`
unterstützt ausgerichtete Tabellen, JSON-Objekte und RFC-4180-CSV. Pro Aufruf
ist genau eine Anweisung erlaubt. Standardmäßig läuft sie in einer von der
Datenbank erzwungenen schreibgeschützten Transaktion. `--allow-mutation`
ermöglicht transaktionale `INSERT`-, `UPDATE`-, `DELETE`- und `REPLACE`-
Anweisungen. DDL bleibt hier ausgeschlossen, da manche Datenbank-Engines DDL
implizit festschreiben. `--limit` begrenzt die zurückgegebenen Zeilen.

`--tenant 42` bindet einen ausdrücklich verwendeten SQL-Platzhalter
`:tenant_id`. Die Option ergänzt keine Mandantenbedingung und macht beliebiges
SQL nicht automatisch mandantensicher.

Die interaktive Zelyra-Sprachkonsole ist getrennt für 1.2.26 geplant. Dafür
braucht es persistenten Interpreterzustand und eine echte Datenbanktransaktion,
die über mehrere Eingabezeilen bestehen kann.
