# Zelyra 1.2.14

Zelyra 1.2.14 improves the invoice tutorial and adds a safe preview for moving
projects toward the standard directory layout.

## Invoice tutorial

- The home page presents its sample invoice as a structured document, with
  distinct line items and a highlighted total. Workflow cards adapt to the
  available screen width.
- Pages using the shared AppShell use the same Zelyra UI foundation and local
  `zelyra.theme.css`. The home page, forms, CRUD cards, invoice overview, and
  print page remain available offline.
- Customer, item, invoice, and line-item pages show a “ⓘ Quelltext erklärt”
  button in the shared header. Its dialog explains the Zelyra source files and
  identifies routes generated by `crud` and `tableview` declarations.
- Generated CRUD cards place labels directly above values. Exact decimals omit
  insignificant trailing zeroes, and Booleans display as “Yes” or “No”. Stored
  values remain unchanged. SKU and unit-price labels are clearer.

## Project layout

- `zelyra migrate-layout --check [entry.zyl] [--format human|json]` creates a
  deterministic, read-only AST preview. Ambiguous and mixed files are marked
  for manual review. It does not move or modify files.
- With the standard layout, `strict_architecture = true` checks a bounded set
  of declaration kinds under `schema/`, `domain/`, and `routes/`, reporting
  violations as `E-ARCH-001`. It is not a full call-graph or effect analysis.

## Verification and limits

The invoice tutorial ran against a disposable MariaDB database in Chromium,
Firefox, and WebKit. Coverage includes CRUD flows, sample data, forms, dialog
interaction, mobile layouts, print styling, and Studio launch. This is not a
claim of complete accessibility certification.

Apache/TLS integration and broader architecture rules remain on the roadmap.
The layout command is explicitly a preview in this release.
