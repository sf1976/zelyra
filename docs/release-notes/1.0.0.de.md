# Zelyra 1.0.0 – Erste produktive Hauptveröffentlichung

Zelyra 1.0.0 ist die erste produktive Hauptveröffentlichung von Zelyra. Alle
geplanten technischen Gates, Datenbankmatrizen, Sicherheitsanalysen und die
unabhängige menschliche Abnahmestudie wurden erfolgreich abgeschlossen.

## Highlights der Version 1.0.0

- **Produktionsreife relationale Datenbankmatrix:** Vollständige und geprüfte
  Unterstützung für MariaDB (10.11, 11.4 LTS), MySQL (8.4 LTS) und PostgreSQL (16+).
  Projektsetup (`zelyra db setup`), typisiertes SQL (`sql_decode`), atomare
  Entscheidungstransaktionen (`with_decision_transaction`) und gehärtete
  Transaktions-Timeouts (`innodb_lock_wait_timeout`).
- **Echte relationale Integrität & Fremdschlüssel:** Durchgängige Unterstützung
  für deklarierte Fremdschlüssel (`references`), echte Datenbank-Constraints,
  Preflight-Waisenprüfung (`error[E-DB-005]`) mit vollständigem Datenerhalt,
  restriktiver Löschschutz und relationale Join-Darstellung in CRUD-Ansichten.
- **Gehärtetes mandantenisoliertes CRUD:** Strikte serverseitige Mandantentrennung
  auf Basis aktiver Benutzer-Mitgliedschaften. Filterung aller Auswahllisten,
  Manipulationsschutz gegen fremde Schlüssel (HTTP 422) und lückenloser Audit.
- **Laravel Migrator 1.0.0:** Statische, schreibgeschützte Code- und
  Migrationsanalyse mit striktem Geheimnis- und PII-Ausschluss, 18 klassifizierten
  Befundarten und compilergeprüfter Gerüstausgabe (`main.zyl`, `zelyra.toml`).
- **100% lokale, souveräne Entwicklungsumgebung:** Lokales Zelyra Studio IDE und
  responsives Rechnungstutorial mit offline verfügbarem Tabler-CSS, automatischer
  MariaDB-Stack-Initialisierung und klarer Fehlerdiagnose.
- **Abgeschlossene unabhängige menschliche Abnahme:** Erfolgreich durchgeführt mit
  dem Kandidaten `v1.0.0-rc.1` auf Debian 12, Ubuntu 24.04 und Windows 11.

## Upgrade und Migration

Projekte aus den 0.9.x-Vorversionen sind vollständig kompatibel. Ein Upgrade der
CLI-Binärdatei erfordert keine manuellen Änderungen an bestehenden Projekten.
Bestehende Schemata können direkt mit `zelyra db apply` inspiziert und validiert werden.
