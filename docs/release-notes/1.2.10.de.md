# Zelyra 1.2.10

Zelyra Studio serialisiert nun Speicherungen von Moduleinstellungen, die im
selben Studio-Prozess eingehen. Beginnen zwei Browseranfragen mit derselben
Revision, wird eine Speicherung übernommen; die veraltete Anfrage erhält HTTP
409 und ersetzt die neue Einstellung nicht stillschweigend. Die API weist
weiterhin ungültige Typen, nicht deklarierte Einstellungen, Symlinks und zu
große Dateien zurück. Tests prüfen, dass Geheimniswerte und gespeicherte
Umgebungsvariablennamen nicht in Antworten erscheinen.

Paketeinstellungen bleiben compilergeprüft und auf das jeweilige Paket
beschränkt. Geheimnisse werden über die Prozessumgebung von Zelyra referenziert
und in Studio nicht als Werte eingegeben oder gespeichert. HostServices bleibt
eine versionierte Rust-Embedding-Schnittstelle; keine stabile native ABI und
kein Paket-Pluginvertrag. Die Offline-CSV-Import-/Exportpakete laufen weiterhin
über die getesteten AST-, MIR- und Bytecode-Teilmengen.

Von Anwendungen ausgelieferte Einstellungsseiten, das Schreiben von
Umgebungsvariablen-Geheimnissen über eine Webseite, ODBC- und Excel-Adapter
sowie vollständige MIR-/Bytecode-Parität sind nicht Teil dieses Releases.
Siehe [Leitfaden zu Moduleinstellungen](../packages.de.md) und
[HostServices-Leitfaden](../runtime-host-services.de.md).
