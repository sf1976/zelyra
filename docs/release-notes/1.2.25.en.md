# Zelyra 1.2.25

Zelyra now includes native database console and direct query commands.

`zelyra db console [main.zyl]` resolves the project's configured database URL
from `ZELYRA_DATABASE_<NAME>_URL` or `DATABASE_URL`, including the project's
`.env`, then starts the installed MariaDB/MySQL or PostgreSQL client. Passwords
are passed through `MYSQL_PWD` or `PGPASSWORD`, never as command-line
arguments. The host client must be installed.

`zelyra db query main.zyl "SELECT id, email FROM customers" --format table`
supports aligned tables, JSON objects, and RFC 4180 CSV. One statement is
accepted per invocation. The default runs in a database-enforced read-only
transaction. `--allow-mutation` enables transactional `INSERT`, `UPDATE`,
`DELETE`, and `REPLACE`; DDL remains unavailable through this command because
some engines commit DDL implicitly. `--limit` bounds returned rows.

`--tenant 42` binds an explicit `:tenant_id` SQL placeholder. It does not add a
tenant predicate or make arbitrary SQL tenant-safe.

The interactive Zelyra language console is planned separately for 1.2.26. It
requires persistent interpreter state and a genuine database transaction that
can span input lines.
