# Zelyra 1.2.41

Dieses Release ergänzt eine bewusst eng begrenzte Laravel-Webseiten-Zuordnung:
`Route::get('/favicon.ico', function () { return
response()->file(public_path('favicon.ico')); });` wird als
gleichursprüngliches statisches Asset importiert.

Der Importer akzeptiert ausschließlich eine nicht gruppierte,
middlewarefreie `GET`-Closure mit einer einzigen wörtlichen Datei aus
`public_path(...)`. Die Routen-URL muss genau dem Dateipfad unter Laravels
`public/` entsprechen. Reguläre Dateien werden über die bestehende begrenzte
und symlinksichere Asset-Pipeline kopiert. Das generierte Projekt dokumentiert
die Zuordnung in `STATIC_ASSET_ROUTES.json` und liefert sie über Zelyras
vorhandenen Public-File-Server aus.

Dies ist keine allgemeine Laravel-Routenunterstützung. Dynamische Antworten,
Middleware, Routengruppen, Controller-Handler und PHP-Ausführung werden nicht
übersetzt. Die Abnahme am echten Projekt `/opt/siedelmann-laravel/app` ist
nur lesend: Sie führt kein PHP aus, liest keine `.env` und untersucht keine
Anwendungszeilen aus der Quelldatenbank. Sie prüft, dass das erzeugte
`/favicon.ico` bytegleich zur Quelle ist und der generierte Scaffold
`zelyra check` besteht.

## Prüfungen

- Die vollständige GitHub-PR-CI bestand auf dem gemergten Quellbaum,
  einschließlich Workspace- und End-to-End-Tests, MariaDB-Kompatibilität mit
  10.11/11.4/11.8/12.3, MySQL 8.4, Dependency Audit, begrenztem Fuzzing und
  Windows-Updater-Prüfung.
- Linux- und Windows-Releasearchive sowie SPDX-SBOMs wurden im PR-Release-Workflow
  erstellt und geprüft. Der versionierte Release-Workflow prüft die
  Release-Artefakte erneut am getaggten Stand.
- Die Abnahme am echten Projekt erfasste 576 PHP-Dateien und 2.274
  Importer-Befunde, prüfte den generierten Scaffold mit dem Compiler und
  verifizierte die bytegleiche Favicon-Zuordnung. Sie behauptet keine
  vollständige Webseitenmigration.

## Installation

Lade das Linux-`.tar.gz`- oder Windows-`.zip`-Archiv aus dem GitHub-Release
herunter und prüfe vor dem Entpacken die zugehörige `.sha256`-Datei.
