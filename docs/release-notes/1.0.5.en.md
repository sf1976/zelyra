# Zelyra 1.0.5

**Released:** 2026-10-14 · **Language compatibility:** `0.1`

Zelyra 1.0.5 improves local diagnostics and removal of user-installed copies,
and completes the invoice tutorial workflow and its bilingual documentation.

## Studio logs

Studio now has a **Logs** panel for recent structured run and web-preview
output. Filter records by level or search their source and message text. Logs
are stored locally as bounded JSONL files, redact values from project and
process secrets, and use owner-only directory and file permissions on Unix.
This captures Studio run/setup events and application or preview stdout and
stderr; it is not a system-wide service logger.

## Uninstall

`zelyra uninstall` identifies the executable that was launched, detects other
Zelyra executables on `PATH`, and asks before removing a user-owned binary.
`--dry-run` reports the selected path without changing files, while `--yes`
confirms non-interactive removal. Package-manager-owned installs are reported
with package-specific guidance. Project files, settings, logs, and database
data are left in place. See the [uninstall guide](../uninstall.en.md).

## Invoice tutorial

- Invoice `issued_at` is a date-only input. Its label and format hint are
  localized (`JJJJ-MM-TT` in German and `YYYY-MM-DD` in English).
- New invoice numbers are assigned by the server from the inserted record ID
  inside the same database transaction. Submitted client values are ignored,
  and editing does not change the generated number.
- The home page now guides users through customer, item, and invoice tasks.
  `/views/invoicedashboard` is presented as the invoice overview.
- The generated project includes English and German guides covering setup
  commands and options, source files, important lines, and the relationships
  between modules. They explain that `crud Invoice -> invoices` generates
  `GET` and `POST /invoices/new`, even though that route is not declared with a
  separate `page` statement.

The [invoice tutorial guide](../tutorials/invoice.en.md) documents Compose
requirements, Studio startup, port selection, sample data, and troubleshooting.
