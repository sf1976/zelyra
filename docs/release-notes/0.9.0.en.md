# Zelyra 0.9.0 — guided business workflows and safe text edits

Zelyra 0.9.0 is an experimental release and is not approved for production
use. Independent human product acceptance remains reserved for the immutable
1.0.0 candidate.

## What is new

- The invoice tutorial walks from a clean project through customers and items
  to a dashboard, invoices, and linked line items. It checks generated source
  with the compiler and runs the workflow against MariaDB.
- When the local Studio guides a CRUD change, it now shows affected source
  files, tables, declared relationships, and generated routes. The compiler
  checks generated source before apply; preview and explicit apply remain
  separate steps.
- `zelyra text edit <plan.zedit>` previews regex edits from a named TOML plan.
  Expected match counts and a source-bound SHA-256 plan ID protect explicit
  apply from changed inputs. The syntax uses Rust regex without look-around or
  backreferences; see the [English guide](../text-edit.en.md) for its limits.
- The 0.1 language compatibility corpus adds typed API errors, a complete
  small invoice application, and `Result` runtime cases.
- Optional local TOTP MFA for MariaDB is an explicitly configured preview.
  The tested scope covers encrypted factors, recovery codes, replay
  protection, session promotion, lockout, and audit. This is not independent
  security approval. Production use remains out of scope until security review
  before 1.0.0.

## Database scope

The exact versions and verified workflows are in the
[database support matrix](../database-support.en.md). It lists MariaDB 10.11,
11.4, 11.8, and 12.3, MySQL Server 8.4.11, PostgreSQL 16, and SQLite
separately. MySQL and PostgreSQL have limited runtime/schema evidence in 0.9;
full CRUD or SQL parity is not included.

## Upgrade and limits

The [0.8.0 upgrade and rollback guide](../upgrades/0.8-to-0.9.en.md) covers
backups, schema review, and the MFA preview. A normal 0.8 project needs no
migration just to replace the Zelyra binary. Optional MFA requires explicitly
adding its tables and protecting a separate encryption key.

Version 0.9.0 does not add external identity providers, multi-tenancy across
arbitrary schemas, full SQL portability, a general job queue, mandatory cloud
services, telemetry, or external AI services. Zelyra's verifier does not prove
arbitrary programs correct. Product release 1.0.0 also requires all technical
gates and independent human product acceptance.
