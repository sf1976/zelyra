# Zelyra 1.2.56

## A database workbench built into Zelyra Studio

Studio now includes a SQL workbench for MariaDB and PostgreSQL. The editor
uses the declared project schema for completion, keeps drafts and recent
queries locally per database, and displays bounded query results. It accepts a
single read-only `SELECT` or `WITH` statement; recognized side-effecting
functions and additional statements are rejected. Result cells are rendered as
text, with limits on rows, columns, and cell length.

Studio also adds typed editors for database records, the original Zelyra logo
on its startup screens, and compiler-guided next-step suggestions for imported
modules, record fields, and eligible CRUD blocks. These suggestions use the
current project model and do not insert code until selected.

## More readable Studio menus

The **File** and **Edit** menus provide common file and editing actions.
**Find and Replace** operates on the active document; project-wide search
remains separate. Menus, toolbars, and the left file sidebar now use larger,
more readable default text. The medium and large font settings remain
available.
