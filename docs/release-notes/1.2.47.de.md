# Zelyra 1.2.47

## Geprüfte hostseitige Funktionsargumente

Wenn ein Host ein Zelyra-Programm über eine öffentliche Funktionsausführung
startet, prüft die AST-Laufzeit die Argumente jetzt anhand der aufgelösten
Parameter- und Generiktypen, bevor Vorbedingungen oder Funktionscode laufen.
AST, MIR und Bytecode melden einen Typfehler mit derselben Diagnose und der
Quellposition des Parameters.

Compiler-generierte Tabellenvalidatoren akzeptieren außerdem die
Datenbankdarstellung von Relationsschlüsseln und `Id`-Aliassen, einschließlich
optionaler Relationen. Die Ausnahme gilt nur für die interne Speicherbrücke;
öffentliche Funktionsparameter behalten ihre deklarierten Zelyra-Typen.

Die Änderung schließt konkrete Paritätsfälle. AST bleibt das Standard- und
Referenzbackend; Bytecode bleibt experimentell und optional. Dieses Release
behauptet keine vollständige Backend-Parität.
