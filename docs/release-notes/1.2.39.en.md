# Zelyra 1.2.39

Zelyra's shared pure standard library now provides
`parse_date(String) -> Result<Date, String>` and
`parse_time(String) -> Result<Time, String>`. They accept only canonical
`YYYY-MM-DD` and `HH:MM:SS` values, validate the Gregorian calendar and
24-hour clock, and return ordinary `Err` values for invalid input. They do not
guess locale formats, timezone offsets, or fractional seconds.

The reusable `csv_import` business package adds explicit `Date` and `Time`
mapping variants. Converted cells remain tagged values, and invalid input
identifies the CSV row and target column. Conversion is opt-in; it does not
infer a database schema or write records. The CSV package remains bounded to
16 MiB and processes input in memory. Database apply, a preview UI, and
timezone-aware timestamp conversion remain outside this release.

`.sha256` file. Extract the archive and place `zelyra` or `zelyra.exe` in a
directory on `PATH`. No npm runtime is required.
