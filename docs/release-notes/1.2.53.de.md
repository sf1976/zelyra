# Zelyra 1.2.53

## Zelyra-spezifisches Schreiben im Studio

Studio ergänzt beim Schreiben automatisch schließende Klammern und
Anführungszeichen und rückt Zelyra-Blöcke mit vier Leerzeichen ein. Tab rückt
die aktuelle Zeile oder Auswahl ein, Umschalt+Tab rückt sie zurück. Die
Einrückung folgt der Zelyra-Blockstruktur und ignoriert Klammern in Kommentaren
und Zeichenketten. So bleibt das Verhalten auch beim Schreiben unvollständigen
Codes vorhersehbar.

Diese Editorhilfen ergänzen Zelyraspezifische Vervollständigung,
Compilerkontext, SQL-Werkzeuge, Datenbankbrowser und die integrierte
Zelyra-Konsole. Zelyra 1.3.0 wird weiterentwickelt; dieser Patch schließt weder
die umfassendere Studio- noch die Sprach-Roadmap ab.
