# Zelyra 1.2.15

Zelyra 1.2.15 makes generated business pages selectively extensible without
replacing their secure CRUD handling with custom routes or forms.

## Customize generated pages

- `crud.view.create` and `crud.view.edit` can define page-specific titles,
  submit labels, and content before or after the generated form. Shared form
  settings still come from `form`; explicitly configured page values take
  precedence.
- Field declarations can show supplemental content, such as customer-number
  guidance below an input. This content uses the checked view context and the
  normal escaping and type checking.
- `tableview` supports additional content before and after the table, as well
  as actions on individual rows. Navigation targets remain links; UI actions
  and server-side changes use the existing safe mechanisms.
- These extensions do not replace generated forms or their validation,
  authorization, CSRF protection, and field allowlist. Supplemental content is
  rendered again after validation errors.

## Invoice tutorial

The item and line-item cards now align labels and values within a cohesive
card. The tutorial continues to use its shared Zelyra UI layout and theme.

## Example and verification

A compiler-checked example is available at
`examples/generated_page_customization/main.zyl`. Release verification covers
compiler and CRUD tests together with the available tutorial and documentation
checks. The release's exact CI and artifact coverage is recorded alongside the
release.
