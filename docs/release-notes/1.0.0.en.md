# Zelyra 1.0.0 — First Productive Major Release

Zelyra 1.0.0 is the first productive major release of Zelyra. All planned
technical gates, relational database matrices, security audits, and the
independent human acceptance study have been successfully completed.

## Highlights of Version 1.0.0

- **Production-Ready Relational Database Matrix:** Full, verified support for
  MariaDB (10.11, 11.4 LTS), MySQL (8.4 LTS), and PostgreSQL (16+). Covers project
  setup (`zelyra db setup`), typed SQL results (`sql_decode`), atomic decision
  transactions (`with_decision_transaction`), and hardened lock timeouts
  (`innodb_lock_wait_timeout`).
- **End-to-End Foreign Keys & Relational Integrity:** Declared references receive
  static compiler validation, genuine database constraints, preflight orphan row
  validation (`error[E-DB-005]`) with full data preservation, restrictive deletion
  defaults, and relational join rendering in generated CRUD.
- **Hardened Multi-Tenant CRUD:** Server-side tenant isolation derived from active
  user memberships across all reads and mutations. Includes isolated relational
  dropdown options, forged key tamper rejection (HTTP 422), and atomic change audits.
- **Laravel Migrator 1.0.0:** Static, read-only Laravel analysis ensuring zero
  leakage of secrets or PII, covering 18 categorized finding kinds, and emitting
  compiler-verified scaffold projects (`main.zyl`, `zelyra.toml`).
- **100% Local, Sovereign Developer Experience:** Self-hosted Zelyra Studio IDE
  and responsive multi-file invoice tutorial with offline Tabler CSS styling,
  automatic MariaDB container startup, and resilient diagnostic reporting.
- **Completed Independent Human Acceptance:** Conducted against published candidate
  `v1.0.0-rc.1` across Debian 12, Ubuntu 24.04, and Windows 11 without blockers.

## Upgrade and Migration

Projects built on 0.9.x are fully compatible. Upgrading the Zelyra binary requires
no manual code changes. Existing database schemas can be inspected and updated
directly using `zelyra db apply`.
