# Zelyra 1.2.11

The invoice tutorial now uses the bundled Zelyra UI styles consistently across
its pages. Generated CRUD forms share the application page frame, and filters,
tables, and mobile navigation use the same design system. The tutorial theme
keeps only project-specific branding and page styling instead of duplicating
framework rules.

`zelyra outbox list` remains read-only and now reports a missing MariaDB outbox
table with `E-OUTBOX-005` and the project-specific
`zelyra outbox setup <file.zyl>` recovery command. Docker Compose detection
accepts Debian and Ubuntu package versions with `~` suffixes. Audit and
auth-role commands resolve database URLs from the
project `.env`. Unix CLI output also follows the normal SIGPIPE behavior when
the output is piped to a command that closes early.

This is a focused maintenance release. Application-served module settings,
complete package parity across AST, MIR, and Bytecode, and the remaining
ecosystem and deployment work assigned to 1.2.12 are not included.
