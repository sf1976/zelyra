# Zelyra 1.2.15 generated page customization

## Goal

Let application authors compose useful, typed content into generated CRUD and
tableview routes while Zelyra retains ownership of routing, validation,
authorization, CSRF protection, and persistence.

## Semantics and limits

The create route has no persisted record; using `record.*` there is a compiler
error. `values.*` represents safe values currently present in the form. Edit
context is limited to selected form fields; identifiers, tenant/owner keys, and
password/token/secret/hash fields are unavailable. Tableview actions can use
only declared SQL result fields that are also displayed in the table columns.
Custom content cannot introduce a nested HTML form or a separate data mutation
path. A button inside field content must explicitly be `type="button"`, so it
cannot accidentally submit the generated form. This package does not replace
generated CRUD forms wholesale or create a new action/event system.
